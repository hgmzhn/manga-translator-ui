# 漫画翻译

根据原文与画面完成自然、准确的译文，负责文字内容的理解、翻译和写入。
以用户指定的页面、区域和目标语言为范围；目标语言优先使用明确要求，其次使用当前工程设置。只要求文字译文时直接给出译文，不修改页面。

## 结合画面理解原文

先按阅读顺序理解对话、人物关系与情绪，再对应每个 region_id 的原文和译文。使用当前提供的图片与区域数据；有读取、搜索或观察工具时按需补足上下文。
原文缺失、OCR 疑似误识别、说话人不明或句子跨气泡时，先结合可见画面和前后对白判断。无法可靠确认的内容保留具体疑点，不编造看不见的原文或剧情。

- 保留事实、否定、程度、数字、人名与前后逻辑；区分对白、内心独白、旁白和拟声词。
- 使用符合人物口吻的自然表达，保留情绪与称呼关系；同一人物、术语保持一致。
- 保留有叙事作用的停顿、重复和强调。可以调整语序，但不能为凑气泡删掉信息或添加原文没有的意思。
- 跨气泡的句子连起来应通顺；不要因 OCR 的换行机械切断译文，也不要擅自把文字移到其他区域。

## 提交译文

普通译文通过 edit_regions 的 translation 字段写入，例如：

```json
{"page_id":1,"command_id":"translate-001","edits":[{"region_id":"r1","translation":"真让人羡慕！"}]}
```

使用实际页面 id 和 region_id，可以合并同一页内已确定的译文修改。工具返回后确认译文已写入，再继续尚未处理的文字区域。
需要修改 translation_rich 的节点结构或局部样式时，先读取 rich-text skill，再用 edit_rich_text 编辑。

## 完成与汇报

核对任务范围内是否有漏译、错译、称呼或术语不一致，交代仍无法确认的原文与译法。
任务还包含排版检查或调整时，译文提交后转到 manga-layout skill，基于最新渲染图继续完成；翻译阶段完成不能代替整个任务完成。
只要求翻译时，简述译文结果及剩余疑点，不附带未经执行的排版结论。
