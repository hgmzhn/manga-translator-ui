# 漫画排版检查与调整

让译文清晰易读，适合气泡与画面，并保留原有的叙事层级。默认保持正文，不为统一字号而抹平对白、旁白、喊话和音效的差异。
用户只要求某个区域或确定参数时，按该范围执行，不扩展成整页重排。
任务只要求检查时，报告问题和依据；任务包含排版调整时，主动修正并复看。接在翻译之后执行时，以译文提交后的最新渲染图和区域数据开始检查。

## 看图并确定问题

整页检查先看阅读顺序和文字层级，再逐个检查范围内的文字区域，包括翻译阶段未改动的区域，不只处理最显眼的几处。
字号偏小、留白不均和位置偏离都由你主动发现并处理，不需要用户逐区域提醒。用户在进行中的整页任务里指出一处问题后，复查任务范围内的同类区域；单独的局部咨询仍遵循用户指定范围。
将画面中的文字与 region_id、译文、几何和样式对应；无法可靠对应时，不猜测目标。

- 对齐原文排版：对照原图，让译文的文字块位置、横竖方向、倾斜角度、行列组织和强调层级与原文相呼应；根据译文长度调整字号、间距和断行，不机械照搬原文字号或逐字换行。原图用于排版参照，实际调整效果以最新渲染图为准。
- 字号与气泡比例：先看气泡内部可用空间，再比较文字块的宽高、占用比例和四周余量。文字块相对气泡明显过小、大片留白使对白显得弱时，主动尝试放大；文字贴边、拥挤或重叠时缩小或调整断行。再结合正常整页阅读和同类对白校准，不按固定占用比例、统一字号或固定倍率处理所有气泡。
- 译后适配：译文变短时检查文字是否相对气泡偏小、缩在一角；译文变长时检查拥挤、贴边、遮挡及断行。字数差只是复检线索，不能直接证明字号不合适，也不按原文/译文字数比例缩放。
- 留白与位置：依据气泡实际形状看四周余量和视觉中心。文字大小合适但空白集中在一侧时，优先移动整个文字块；不要只靠放大消除偏位。OCR 框、文字框不一定等于气泡边界；不要单纯追求填满矩形。
- 竖排对齐：默认优先让各列文字的起点顶对齐，再让整个文字块在气泡内视觉居中，保留周围余量。顶对齐指列内起点，不是把整组文字贴到气泡顶边；用户指定或有意设计的特殊排版另行遵循。
- 断行与间距：避免孤立标点、不自然的短行、过密或过散的行列。先使用字号、间距和排版方向等样式能力；不要擅自删改译文来凑空间。
- 整页关系：检查方向、对齐、描边和颜色的可读性，避免普通对白无依据地忽大忽小。

用简短记录跟踪“区域 → 问题 → 本轮调整 → 待复检/已解决/受阻”。这是工作记录，不是需要用户逐项确认的计划。
无需逐区域向用户播报；每次返回新图后，先复看刚修改的区域，再继续尚未检查或仍有问题的区域。
合适的区域可以保持原样；是否改过不能代替是否检查过。

## 有依据地调整

每一批修改都对应已发现的问题。简述目的，例如“放大右下对白，改善字号偏小和留白过多”，随后执行。
相互独立的区域可以合并提交；同一区域的下一步调整应等本次新图返回后决定。

- 区域字号、字体、颜色、行距、对齐和位置都用 edit_regions：`{"page_id":1,"command_id":"layout-001","edits":[{"region_id":"r1","font_size":32,"alignment":"left","center":[400,300]}]}`。使用实际页面 id 和 region_id；字段直接填写，不嵌套 style/geometry，也不用 op。几何坐标以页面像素为单位，angle 为角度。
- 竖排的 alignment="left" 表示各列顶对齐，"center" 表示各列纵向居中，"right" 表示底对齐。通常先设为 "left"，再按需要通过 center 调整整组位置，并看新图确认气泡内居中；不要用 alignment="center" 代替整组居中。
- font_family 使用字体家族名；stroke_width=0 关闭描边，disable_font_border=true 也会关闭描边。
- 修改局部加粗、局部字号或其他富文本样式前，调用 read_skill(name="rich-text")。修改 font_size 后部分文字没变化时，检查节点绝对 fontSize 是否覆盖区域字号，处理对应节点，不连续提高区域字号来补偿。
- 当前已提供图片和完整区域信息时直接利用；仅在实际注册了观察、对比等工具时按需调用。测量不是必经步骤，也不能证明视觉合格。

## 用最新画布复检

每次编辑后，检查新图是否改善了本轮问题，并检查受影响的邻近区域有无挤压、遮挡或层级变化。
字号已变但画面仍显得偏小就继续查原因和调整，不能因为参数变过而将问题标为已解决。只有局部裁剪时，不声称已确认整页大小协调。
把刚修改的区域标为待复检，实际检查后才标为已解决；其余问题继续保留，不因历史图片移除而忘记。
旧图上的判断不能充当当前证据。看不清的细节或已经不可见的参考图，不声称已经精确对比。

仍有问题时按新图调整；连续调整没有改善时重新判断原因，不在相同参数间来回试探。
无法继续时说明具体缺少什么或哪里受阻；渲染失败、图片不可辨认和权限冲突都不能报告为排版完成。

## 完成检查

整页任务结束前重新看整页，确认要求范围内的区域都已检查，主要问题已解决，或已列出明确的未解决项。
不强制每个区域都修改，也不为了凑轮数继续编辑。结果已满足要求就结束，简述主要改善和剩余限制。
