## Reporting a Vulnerability

We take the security of Manga Translator UI seriously. If you believe you have found a security vulnerability in this project, please follow these steps to report it responsibly:

### How to Report

1. **Do not create a public issue** to report a security vulnerability.
2. Please submit a report privately via **GitHub Security Advisory**:
   - Navigate to [Security Advisories](https://github.com/hgmzhn/manga-translator-ui/security/advisories)
   - Click **"Report a vulnerability"**
3. Alternatively, you may contact the maintainer directly via email:
   - Email: **hgmzhn@gmail.com** (or reach out to repository maintainers)

### Information to Include

To help us triage and resolve the issue quickly, please include:
- A description of the vulnerability and its potential impact.
- Clear steps to reproduce or a Proof of Concept (PoC).
- The affected component, version, and environment details (e.g., OS, Python version).
- Any proposed remediations or patches if available.

### Response Timeline

- **Initial acknowledgment**: Within 48 hours of report submission.
- **Triage and confirmation**: Within 7 business days.
- **Fix and public release**: We strive to release a patch or workaround as soon as practicable, after which an advisory will be published acknowledging the reporter (unless anonymity is requested).

Thank you for helping keep Manga Translator UI and its community secure.
