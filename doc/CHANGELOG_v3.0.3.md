# v3.0.3 更新日志

发布日期：2026-08-21

## ✨ 新功能

### FLUX.2 Klein 修复模型
- 新增 FLUX.2 Klein 4B 修复模型，可在修复模型设置中选择 `flux2-klein`。
- NVIDIA CUDA 环境仅在可用时尝试启用 xformers；ROCm 不进入 CUDA 专用的 xformers 路径。

### 气泡蒙版排版
- 新增 `render.balloon_fill_mask_layout` 开关，仅在智能气泡（`balloon_fill`）排版模式下生效，默认关闭以保持原有行为。
- 开启后，无显式断行的文本按气泡蒙版最大内接范围重新断句；已有显式断行则完整保留，并以文本框中心为锚点把字号搜索范围扩大到气泡边界。
- 气泡蒙版缺失或未完整包裹 OCR 文本行时使用保守回退；后续文字框与已有文字框重叠时，缩小到最大不重叠字号。

## 🐛 修复与改进

### 编辑器蒙版修复期间立即保存
- 编辑器蒙版修复尚未完成时，点击保存直接写入当前内存中的工程快照，不再提示、等待或拒绝保存。
- JSON 保存当前蒙版，修复图保存画布当前正在显示的修复图；修复完成后再次保存即可写入最新修复结果。

### 编辑器重复蒙版笔画重修
- 修复优化蒙版的画笔覆盖已有蒙版区域时，因二值蒙版无差异而跳过修复的问题；现在无需先擦除，重复涂抹会重新修复画笔触及的完整蒙版连通块，其他不相连区域保持不变。
- 重修笔画已直接纳入现有 delta/artifact 流水线，并通过 `InpaintKey` 淘汰连续操作中的过期异步结果。

### 旋转文本框导出位置修复
- 修复旧工程区域未保存 `center` 时，编辑器导出跳过白框中心换算，导致文字沿区域旋转方向偏移、成图与画布预览位置不一致的问题。
- 导出现在与编辑器画布共用 `lines` 的中心回退规则；富文本单字旋转（例如竖排波浪号的 `rotation: -90`）保持不变。

### 编辑器多行文本空格修复
- 修复在编辑器中修改多行文本时，除第一行外其他行的行首空格会被自动删除的问题（[#246](https://github.com/hgmzhn/manga-translator-ui/issues/246)）。
- 换行与富文本段落转换现在会保留用户手动输入的行首、行尾空格。

### OpenCV 5 面板检测兼容
- 修复 OpenCV 5 将 LSD 线段返回形状从 `(N, 1, 4)` 改为 `(N, 4)` 后，面板检测触发 `IndexError: invalid index to scalar variable` 并回退简单文本排序的问题。
- 面板线段解析现在同时兼容 OpenCV 4 和 OpenCV 5 的返回布局，多分格漫画可继续按面板阅读顺序排列文本。

### 超分临时目录清理
- 修复 ESRGAN 和 Waifu2x 超分进程失败或图片读写异常时未清理输入、输出临时目录的问题，避免 `%TEMP%` 持续积累临时文件。

### curl_cffi Windows 证书路径修复
- 修复 Windows 下应用目录或虚拟环境路径包含非 ASCII 字符时，`curl_cffi` 读取 CA 证书路径失败并报 cURL error 77 的问题。
- 创建 curl_cffi 会话时，证书相关文件路径按 Windows 系统代码页传递给 libcurl；继续保留 HTTPS 证书校验。

### Windows 中文路径模型下载修复
- 修复应用或模型目录包含中文等非 ASCII 字符，并以无控制台方式启动时，预处理阶段自动下载缺失模型会因 `sys.stdout` 为 `None` 而触发 `'NoneType' object has no attribute 'isatty'` 的问题。
- 下载进度现在仅使用可写的标准流；桌面进程没有控制台时自动禁用进度条，不影响模型写入和后续预处理。

### 自动更新版本来源修复
- UI 自动检查、维护工具和发布 Action 统一使用 `packaging/VERSION` 作为唯一应用版本来源。
- 不再读取或写入打包目录根部的 `VERSION` 文件，避免代码已更新到新版本但 UI 仍显示旧版本、反复提示更新的问题。

### ONNX Runtime CUDA 提供者警告修复
- 修复 Windows 下使用 ONNX Runtime 1.28 加载 PaddleOCR ONNX 模型时，显式传入 `device_id=0` 触发 `No registered plugin EP device found` 警告的问题。
- CUDAExecutionProvider 现在默认使用设备 0，仅在调用方明确提供时传递额外 CUDA 参数；保留 CUDA 会话失败时自动回退 CPU 的行为。

### PaddleOCR-VL 参数文档警告修复
- 修复 Transformers 5.15.0 加载 PaddleOCR-VL 图像处理器时，因 `min_pixels` 和 `max_pixels` 未出现在自动生成文档中而输出 `[ERROR]` 日志的问题。
- 通过应用内运行时兼容补丁补齐缺失文档，不直接修改 `.venv` 或系统 `site-packages` 文件；不改变图像缩放和推理参数行为。

### 自动断句几何匹配修复
- 修复无显式换行文本依赖 OCR `region.lines` 数量决定目标行列，导致译文无法适配实际文本框形状的问题。
- 自动断句现在枚举行数/列数组合，复用现有横排、竖排和文本尺寸测量算法，选择与传入布局矩形宽高比例最接近且不溢出的候选。
- 保留 OCR 单行区域的原有不换行特殊处理；多行区域不再使用 `region.lines` 数量作为自动断句目标。
- 中文语义断句仍优先使用 HanLP 语义边界；矩形形状搜索只选择候选行列数，模型不可用时回退普通换行。
- 智能气泡模式先使用气泡蒙版最大内接矩形进行形状匹配，再执行最终蒙版容纳检查。

### 字体大小滑块同步修复
- 修复属性面板字体大小输入框与滑块在区域切换、模型回写或连续调节时偶发显示错位的问题；两个控件现在通过单一同步入口更新，并在程序化刷新期间统一阻塞信号。
- 字号输入框继续支持 `8–1000`，滑块保持适合拖动的 `8–150` 范围；字号超过 150 时保留输入框真实值，滑块停在上限，不会反向截断字号。

### 多选文本框样式值显示修复
- 修复通过框选或 `Ctrl+A` 多选文本框时，样式设置中的字体大小、颜色、描边、间距、角度、字体、对齐方式和方向等数值被重置为默认值的问题。
- 多选时现在沿用第一个选中文本框的样式值显示，同时继续清空并禁用文本内容编辑，避免误显示某个区域的文本。

### 富文本字号起始值改进
- 富文本编辑器新增字号属性时，起始值改为当前选中文本框的实际字号，不再固定使用 24，便于基于现有排版继续调整（[#249](https://github.com/hgmzhn/manga-translator-ui/issues/249)）。

### 属性编辑器快捷符号面板
- 在属性编辑器的译文框下方新增 Fluent 快捷符号按钮；面板按参考工具的符号栏提供全角/半角标点、竖排引号、波浪号、心形、圆形、音符、实心方形和全角空格，并在当前光标或选区处插入。
- 删除译文框下方的字符数显示，避免占用属性面板的垂直空间。
- 符号按钮保留原符号外观，并为每个符号提供独立的简体中文、繁体中文、英文、日文、韩文和西班牙文名称；全角空格显示为空白按钮，通过本地化悬浮提示说明用途。
