# v3.0.3 更新日志

发布日期：2026-08-21

## 🐛 修复与改进

### ONNX Runtime CUDA 提供者警告修复
- 修复 Windows 下使用 ONNX Runtime 1.28 加载 PaddleOCR ONNX 模型时，显式传入 `device_id=0` 触发 `No registered plugin EP device found` 警告的问题。
- CUDAExecutionProvider 现在默认使用设备 0，仅在调用方明确提供时传递额外 CUDA 参数；保留 CUDA 会话失败时自动回退 CPU 的行为。

### PaddleOCR-VL 参数文档警告修复
- 修复 Transformers 5.15.0 加载 PaddleOCR-VL 图像处理器时，因 `min_pixels` 和 `max_pixels` 未出现在自动生成文档中而输出 `[ERROR]` 日志的问题。
- 通过应用内运行时兼容补丁补齐缺失文档，不直接修改 `.venv` 或系统 `site-packages` 文件；不改变图像缩放和推理参数行为。

### 自动断句几何匹配修复
- 修复无显式换行文本的候选评分只关注行列数、标点和长度均匀度，可能选中虽然均匀但明显超出 OCR 文本框的横排或竖排方案的问题。
- 自动断句现在会将候选文本块相对 OCR 整体框的宽度和高度超出比例纳入软评分，并保留 5% 容差；候选不会被硬淘汰，但超出过多时会优先选择更接近原区域形状的布局。
- 修复目标行列数大于 2 时允许“目标数减一”导致的异常降行问题；例如初始目标为 3 列时，不再因为两列长度更均匀而选择高度严重超出的两列方案。
- 统一横排行距的估算与实际渲染口径：初始行数计算、显式断句优化和智能缩放重算均改用共享行距函数，正确应用 `line_spacing` 配置，不再使用与实际渲染不一致的固定 `0.01` 系数。
- 智能气泡模式会先获得更符合 OCR 整体宽高的断句结果，再根据气泡蒙版调整字号，减少文字过长、字号被过度缩小及文本块比例失真的情况。

### 字体大小滑块同步修复
- 修复属性面板字体大小输入框与滑块在区域切换、模型回写或连续调节时偶发显示错位的问题；两个控件现在通过单一同步入口更新，并在程序化刷新期间统一阻塞信号。
- 字号输入框继续支持 `8–1000`，滑块保持适合拖动的 `8–150` 范围；字号超过 150 时保留输入框真实值，滑块停在上限，不会反向截断字号。

### 多选文本框样式值显示修复
- 修复通过框选或 `Ctrl+A` 多选文本框时，样式设置中的字体大小、颜色、描边、间距、角度、字体、对齐方式和方向等数值被重置为默认值的问题。
- 多选时现在沿用第一个选中文本框的样式值显示，同时继续清空并禁用文本内容编辑，避免误显示某个区域的文本。

### 属性编辑器快捷符号面板
- 在属性编辑器的译文框下方新增 Fluent 快捷符号按钮；面板按参考工具的符号栏提供全角/半角标点、竖排引号、波浪号、心形、圆形、音符、实心方形和全角空格，并在当前光标或选区处插入。
- 删除译文框下方的字符数显示，避免占用属性面板的垂直空间。
- 符号按钮保留原符号外观，并为每个符号提供独立的简体中文、繁体中文、英文、日文、韩文和西班牙文名称；全角空格显示为空白按钮，通过本地化悬浮提示说明用途。
