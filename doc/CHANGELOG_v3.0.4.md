# v3.0.4 更新日志

发布日期：2026-08-29

## ✨ 新功能

### 贴片（图块叠加）功能
- 在桌面端编辑器中新增贴片（Paste Overlay / 图块叠加）功能，支持将修图素材、手写字、印章或补图作为独立图层置入画布（[#264](https://github.com/hgmzhn/manga-translator-ui/pull/264)）。
- 支持直接拖拽外部图片（PNG、JPG、WebP、BMP 等）或通过剪贴板（`Ctrl+V`）粘贴到画布鼠标位置；支持选择、多选、自由拖动移动、八向控制柄缩放、旋转手柄、`Ctrl+滚轮` 缩放以及 `Ctrl+C` / `Ctrl+V` / `Delete` 快捷键。
- 支持调整贴片透明度（0%~100%）、图层层级排序（置顶/置底/上移/下移）与显隐切换，操作与文本框选择互不干扰。
- 完整接入工程文件（`.json` / `.mtproj`）序列化与撤销/重做（`Ctrl+Z` / `Ctrl+Y`）历史栈；导出时贴片以预乘 Alpha 自动无损合成至底图与文本层之间，同时支持纯贴片无文字区域页面的独立导出。

## 🐛 修复与改进

### AVIF 读写兼容性修复
- 修复并发渲染流程保存 `*_inpainted.avif` 时误用 OpenCV 编码器导致 AVIF 写入失败的问题，统一改用 Pillow AVIF 编码。
- 修复 MangaLens 气泡检测直接通过 OpenCV 读取 AVIF 路径失败的问题，路径输入改用 Pillow 安全解码；保持标准 `.avif` 格式，不新增非标准扩展名。

### 字体下拉列表新字体动态感知
- 修复向项目 `fonts/` 目录新增字体文件后，点击字体下拉列表不会自动识别并刷新的问题。
- 将轻量级字体目录签名与文件扫描前置到字体查询入口，在未新增字体时保持微秒级 LRU 缓存直出，避免每次打开下拉框全量重新解析字体的性能顿挫；在新增或变动字体文件时自动失效缓存并增量注册新字体。

### EPUB 导入阅读顺序与原图提取优化
- 修复导入 EPUB 漫画时，因直接遍历 ZIP 物理条目导致文件名带有 `0003_moe-017804` 等内部标识且页面乱序的问题；改为严格按 EPUB 规范清单（`container.xml` 与 `<spine>`）的书脊顺序排列。
- 提取流程优先按阅读顺序从 ZIP 中解压出原始高清图片（零损耗保留原图分辨率与格式），并统一命名为与 PDF 一致的 `page_{count:04d}.{ext}` 格式。
- 对纯文字/SVG/无独立原图页面自动回退调用 PyMuPDF (`fitz`) 渲染补齐，并追加扫描未被显式引用的隐藏插图，彻底解决导入 EPUB 时少页、漏页的问题。

### 蒙版修复 mask_shape 参数修复
- 修复在非 `fit_text` 蒙版优化模式下调用 `complete_mask_fill` 时缺失 `mask_shape` 参数导致 `TypeError` 的问题（[#267](https://github.com/hgmzhn/manga-translator-ui/pull/267)）。

### 文本翻译 dispatch 参数传递修复
- 修复翻译服务向 `dispatch` 传递已弃用关键字参数导致 `TypeError` 的问题（[#266](https://github.com/hgmzhn/manga-translator-ui/pull/266)）。

### Renderer、Colorizer 与 OCR 错误分类
- 修复在线 Renderer、Colorizer 和 OCR 请求失败时被归类为通用 API、模型或多模态错误的问题。
- 根据实际生产日志识别候选耗尽、模型不支持和图片输出能力不兼容等错误，保留对应功能的专用提示。
- 支持 `exhausting 1 API candidate`、`exhausting 1 API candidate(s)` 和 `no available API candidates` 等候选耗尽格式。

### OCR 错误提示
- 新增 OCR 专用错误文案，区分本地 OCR 与在线 OCR 的处理建议。
- 使用本地 OCR 时提示不要选择 `OpenAI OCR` 或 `Gemini OCR`；使用在线 OCR 时提示检查 API 密钥、地址、通道和模型配置。

### 多语言错误文案
- 同步更新简体中文、繁体中文、英文、日文、韩文和西班牙文的 Renderer、Colorizer、多模态及 OCR 错误提示。
- 在线选项文案只提示不要选择对应在线功能，不固定指定某个本地模型，避免后续新增本地模型后提示失效。

### 跨区域文字描边
- 修复相邻或重叠文本区域中，后绘制文字的字体描边覆盖前面文字正文的问题。
- 将特效层、描边层和正文层分阶段绘制，确保所有正文位于描边之上。

### 纯色气泡直接填色范围
- 修复纯色气泡直接填色覆盖整个气泡的问题。
- 现在气泡蒙版只用于识别候选气泡，实际填色限制在优化修复蒙版与气泡蒙版的交集内，避免擦除修复蒙版之外的气泡内容。

### 无文字页面蒙版
- 修复未检测到文字区域时将检测器原始热力图作为 `mask_raw` 写入工程 JSON 的问题。
- 无优化蒙版时不再回退保存原始检测蒙版，空页面 JSON 不写入 `mask_raw` 和 `mask_is_refined`。
