# v3.0.2 更新日志

发布日期：2026-08-16

## 🐛 修复与改进

### 本地工程文本只读导出
- 新增“仅从本地 JSON 导出文本”参数，同时控制“导出翻译”和“导出原文”，默认关闭。
- 开启后只读取已有工程 JSON 并生成对应文本副文件，不重新检测图片、不执行 OCR、不调用翻译 API，也不回写工程 JSON，避免覆盖用户已修改的译文。
- 找不到工程 JSON 时会明确报错且不回退 OCR；关闭参数时继续使用原有导出流程。
- 设置页和管理员权限编辑器均已加入该参数。

### 竖排破折号连续渲染修复
- 修复竖排连续破折号使用两个独立破折号字形时，连接处出现空隙或重叠的问题。
- 竖排替换规则现在直接将长破折号 `—` 转为表格框线字符 `│`；`——` 自然得到 `││`，不再进入富文本旋转规则。
- 删除破折号位图补齐、相邻负字距和额外像素重叠等特殊布局处理；短破折号 `–` 仍转为竖排形式 `︲`。

### 富文本编辑器数值显示修复
- 修复描边、发光、外描边和偏移数值框被上下箭头挤占，导致数值显示不完整的问题。
- 隐藏上述数值框的上下箭头，同时保留鼠标滚轮调整数值。

### 富文本宽高独立拉伸
- 浮动富文本编辑器新增 `WH` 样式；选中文字后可分别调整宽度（W）和高度（H）倍率，`1.00` 保持原尺寸，大于 `1.00` 拉伸，小于 `1.00` 压缩。
- 新增 `transform.scaleX` 与 `transform.scaleY` 富文本字段，并同步支持富文本规则、样式摘要和预设。
- 拉伸直接变换字形矢量轮廓后再光栅化，描边、外描边和发光基于拉伸后的轮廓生成，避免放大已有位图造成文字模糊。

### 编辑器右键菜单国际化
- 编辑器画布右键菜单已接入 i18n，OCR、翻译、复制、粘贴样式、删除、新建文本框、粘贴区域和刷新视图会随界面语言切换。
- 补齐简体中文、繁体中文、英语、日语、韩语和西班牙语菜单文案，删除项保留选中区域数量。

### 海外赞助入口优化
- 将 Ko-fi 海外赞助入口提升到二维码上方，使用高对比度强调卡片、说明文案和加大按钮，避免被国内二维码区域弱化。
- 补齐六种界面的海外赞助提示文案。

### 文本方向快捷键
- 编辑器新增 `V` 快捷键，可将选中文本框在横排与竖排之间切换；多选时以最后选中的文本框为基准统一应用方向。
- 焦点位于文本输入框时，`V` 仍输入普通字符，不会误改文本方向。
