# 代码索引

这个索引把功能页提到的代码文件按目录归类，并列出引用它们的页面。需要查实现位置时从这里进入；只想完成翻译或排障时，直接看对应功能页即可。

索引数据来自各页「代码位置」表的“文件”列。行号与锚点会被去掉，路径统一为仓库相对路径；方法名、目录、glob 和大括号展开会按页面原文保留。页面链接指向当前语言的对应页面。

## 使用说明 {#usage}

- 同一源码文件在同一页面只计一次。
- 一个源码文件可能被多个页面引用，表格中的链接会重复出现；被引用页数最多的文件见[汇总统计](#coverage-overview)。
- 无法对应到具体文件的引用（方法名、目录、glob、大括号展开或页面原文写法）会按原文保留在对应分组。
- 这里是开发者索引，不替代功能页；文件格式、参数默认值和工作方式仍以对应功能页为准。
