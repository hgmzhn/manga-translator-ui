# v3.1.0 更新日志

发布状态：待发布

## 🐛 修复与改进

### Photoshop 安装路径检测

- 修复 Photoshop 安装在 D 盘等非系统盘、已设置 `PHOTOSHOP_PATH` 但仍提示未找到安装的问题。检测时支持读取 Windows 当前保存的用户和系统环境变量，兼容应用启动后新增或修改变量的情况。
- `PHOTOSHOP_PATH` 支持带引号的路径、安装目录及环境变量展开；新增 Windows App Paths 注册表查询，兼容用户和系统级、32 位和 64 位注册表记录。

### 波斯语 ZWNJ 与文字顺序

- 修复翻译结果在预整形和双向重排时丢失波斯语零宽不连字字符 ZWNJ（`U+200C`）的问题，例如 `درخت‌ها` 中的 ZWNJ 现在会保留在译文、编辑和保存的数据中。
- 译文保留原始 Unicode 逻辑顺序，横排由 Qt 处理连字和双向文字，修复波斯语、阿拉伯语与拉丁文字混排时拉丁字符被错误反转的问题。
- 修复竖排将 ZWNJ 和 ZWJ（`U+200D`）当作缺失字形绘制为问号、额外占用字符位置的问题。

### 排版方向与旧方案兼容

- 排版方向选项统一为 `auto`、`h` 和 `v`，后端根据显式设置、目标语言或文本框形状解析为横排或竖排；阿拉伯语和波斯语默认横排，自动对齐按语言判断。
- 旧工程及批量方案中的 `hr`、`vr` 作为兼容输入分别归一为 `h`、`v`；修复旧方案的竖排条件或批量赋值在下拉框加载时被误选为横排的问题。
