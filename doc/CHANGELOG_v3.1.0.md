# v3.1.0 更新日志

发布状态：待发布

## ✨ 新功能

### 翻译页文件管理

- 新增文件夹列表与图片缩略图混合浏览，文件夹默认折叠，展开后在原位显示多列缩略图，支持双击图片打开编辑器。
- 支持勾选、拖动框选和批量清除；选中项目后，「清空列表」自动切换为「清除选中」。
- 扩大文件浏览区域，将输出目录、工作流和开始按钮集中到底部；移除项目或刷新列表时保留浏览位置和目录展开状态。

## 🐛 修复与改进

### 智能气泡排版性能与气泡外文本

- 优化智能气泡排版的最大内接矩形搜索，在关联气泡的局部范围内计算，并无损合并连续相同的行列，减少大图排版时的整页扫描，保持原始像素尺寸与矩形选择结果。
- 优化气泡区域蒙版提取和多边形包含检查，复用连通区域标签，在局部范围内填充文字多边形，减少临时数组分配与扫描，保持像素级判断规则。
- 修复开启气泡蒙版排版时，气泡外文本跳过自动换行的问题。未被气泡完整包裹的区域回退到严格文本框布局，按原文本框断行并适配字号；气泡内区域继续使用气泡布局。

### 编辑器多选复制粘贴与渲染稳定性

- 修复选中多个文本框时只能复制粘贴其中一个的问题，快捷键、属性面板复制按钮和右键菜单均支持复制整个选择集（[#286](https://github.com/hgmzhn/manga-translator-ui/pull/286)）。
- 整组粘贴时保持文本框之间的相对位置，粘贴后自动选中整组，支持一次撤销或重做；修复部分文本框粘贴后位置偏移、组内相对位置改变的问题。
- 修复无可渲染文字或渲染尺寸为零的区域触发渲染异常的问题，空区域正确跳过文字绘制。

### PaddleOCR 长对白识别

- 修复 PaddleOCR 长对白被横向压缩到 320 像素、导致错字或识别为空的问题；动态宽度模型按文字区域宽高比调整输入宽度（[#285](https://github.com/hgmzhn/manga-translator-ui/pull/285)）。
- 按文字宽度分组处理，减少长短行混合批次的补齐与内存开销，保持识别文字与颜色结果正确对应原区域；固定宽度模型继续使用模型要求的宽度。

### 跟随系统主题

- 修复 macOS/Linux 下「跟随系统」无法识别深色外观的问题，统一通过 Qt 跨平台接口读取系统主题，支持 Windows、macOS 和提供系统外观信息的 Linux 桌面环境（[#284](https://github.com/hgmzhn/manga-translator-ui/issues/284)）。
- 系统深浅色切换后通过通知更新界面，无需等待原先的 5 秒轮询；仅在「跟随系统」模式下响应，手动选择的主题不受影响。
- 系统切回浅色时恢复已保存的用户主题偏好，自动切换不再覆盖偏好；无法识别系统外观时，启动使用已保存偏好，运行中保留当前主题。

### Photoshop 安装路径检测

- 修复 Photoshop 安装在 D 盘等非系统盘、已设置 `PHOTOSHOP_PATH` 但仍提示未找到安装的问题。检测时支持读取 Windows 当前保存的用户和系统环境变量，兼容应用启动后新增或修改变量的情况。
- `PHOTOSHOP_PATH` 支持带引号的路径、安装目录及环境变量展开；新增 Windows App Paths 注册表查询，兼容用户和系统级、32 位和 64 位注册表记录。

### 波斯语 ZWNJ 与文字顺序

- 修复翻译结果在预整形和双向重排时丢失波斯语零宽不连字字符 ZWNJ（`U+200C`）的问题，例如 `درخت‌ها` 中的 ZWNJ 现在会保留在译文、编辑和保存的数据中。
- 译文保留原始 Unicode 逻辑顺序，横排由 Qt 处理连字和双向文字，修复波斯语、阿拉伯语与拉丁文字混排时拉丁字符被错误反转的问题。
- 修复竖排将 ZWNJ 和 ZWJ（`U+200D`）当作缺失字形绘制为问号、额外占用字符位置的问题。

### 排版方向与旧方案兼容

- 排版方向选项统一为 `auto`、`h` 和 `v`，后端根据显式设置、目标语言或文本框形状解析为横排或竖排；阿拉伯语和波斯语默认横排，自动对齐按语言判断。
- 旧工程及批量方案中的 `hr`、`vr` 作为兼容输入分别归一为 `h`、`v`；修复旧方案的竖排条件或批量赋值在下拉框加载时被误选为横排的问题。

### 横排行距与描边宽度

- 修复横排文字的实际行间距随描边宽度增大的问题。固定字号和行距设置时，调整全局或局部描边宽度不再拉大行距，与竖排保持一致。
- 注音、着重号等组合排版同样按不含描边的字形计算间距，绘制范围仍保留描边所需空间，避免描边被裁切。

### 字号设置与富文本优先级

- 固定字号、字号偏移、缩放比例和最小/最大字号统一在自动排版及重叠避让完成后应用一次，修复气泡蒙版排版继续缩小固定字号、限制比例或偏移放大，以及异常回退跳过字号设置的问题。
- 修复自动富文本规则命中后重复应用字号偏移和缩放比例的问题，即使规则只修改颜色，也不会再次缩小文字。
- 富文本中单独设置的字号和倍率保持最高优先级；最终按实际字号和局部样式重新测量文字框，保持测量与绘制一致。

### 富文本数值跨零调整

- 修复浮动富文本编辑器中斜体、局部旋转、字前间距、字后间距和 X/Y 偏移在数值经过 0 时立即取消属性、移除数值框的问题。归零后保留属性行，可继续使用滚轮、按钮或键盘跨过 0 调整；切换选区或关闭面板时清理临时零值项。
- 归零导致相邻文本片段合并时，保持当前数值框和相邻文字的属性显示稳定，保留其他已有样式；手动取消属性的行为不变。

### 纵中横间距与描边宽度

- 修复应用纵中横（TCY）的文字占用高度随全局或局部描边宽度增大、推开后续文字的问题（[#282](https://github.com/hgmzhn/manga-translator-ui/issues/282)）。
- 纵中横按不含描边和特效的正文尺寸计算间距，兼容旋转、拉伸及半字/全字推进；描边、外描边与发光所需空间仍计入绘制范围。

### 气泡蒙版与原图绑定

- 气泡蒙版随当前原图保存、传递和清理，避免批量或并发处理时被独立缓存提前淘汰，以及图片内存地址复用导致的蒙版错配。
- 检测与拟声词过滤、OCR 气泡过滤、蒙版修复、纯色气泡填充和智能气泡排版统一复用当前图片的气泡蒙版；补齐从 JSON 加载后重新检测蒙版时向后续阶段传递气泡蒙版的逻辑。

### 字体字重与列表去重

- 修复部分日文字体同时包含传统家族名和排版家族名时，字体列表重复显示、字重漏项，以及加载顺序改变列表结果的问题；按实际字体内容合并重复入口，保留不同字重。
- 字体选择明确保存家族和样式，修复选中 H 等字重后实际渲染为默认 R 字重的问题；旧字体名称经实际字体核对后映射，保持预览与渲染选择一致。
- 字体目录新增、删除或原路径替换字体后，同步更新字体注册、列表和相关缓存，避免继续显示或使用旧字体信息。
