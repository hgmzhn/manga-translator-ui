# v3.1.0 更新日志

发布状态：待发布

## 🐛 修复与改进

### Photoshop 安装路径检测

- 修复 Photoshop 安装在 D 盘等非系统盘、已设置 `PHOTOSHOP_PATH` 但仍提示未找到安装的问题。检测时支持读取 Windows 当前保存的用户和系统环境变量，兼容应用启动后新增或修改变量的情况。
- `PHOTOSHOP_PATH` 支持带引号的路径、安装目录及环境变量展开；新增 Windows App Paths 注册表查询，兼容用户和系统级、32 位和 64 位注册表记录。

### 波斯语 ZWNJ 与文字顺序

- 修复翻译结果在预整形和双向重排时丢失波斯语零宽不连字字符 ZWNJ（`U+200C`）的问题，例如 `درخت‌ها` 中的 ZWNJ 现在会保留在译文、编辑和保存的数据中。
- 译文保留原始 Unicode 逻辑顺序，横排由 Qt 处理连字和双向文字，修复波斯语、阿拉伯语与拉丁文字混排时拉丁字符被错误反转的问题。
- 修复竖排将 ZWNJ 和 ZWJ（`U+200D`）当作缺失字形绘制为问号、额外占用字符位置的问题。

### 排版方向与旧方案兼容

- 排版方向选项统一为 `auto`、`h` 和 `v`，后端根据显式设置、目标语言或文本框形状解析为横排或竖排；阿拉伯语和波斯语默认横排，自动对齐按语言判断。
- 旧工程及批量方案中的 `hr`、`vr` 作为兼容输入分别归一为 `h`、`v`；修复旧方案的竖排条件或批量赋值在下拉框加载时被误选为横排的问题。

### 横排行距与描边宽度

- 修复横排文字的实际行间距随描边宽度增大的问题。固定字号和行距设置时，调整全局或局部描边宽度不再拉大行距，与竖排保持一致。
- 注音、着重号等组合排版同样按不含描边的字形计算间距，绘制范围仍保留描边所需空间，避免描边被裁切。

### 气泡蒙版与原图绑定

- 气泡蒙版随当前原图保存、传递和清理，避免批量或并发处理时被独立缓存提前淘汰，以及图片内存地址复用导致的蒙版错配。
- 检测与拟声词过滤、OCR 气泡过滤、蒙版修复、纯色气泡填充和智能气泡排版统一复用当前图片的气泡蒙版；补齐从 JSON 加载后重新检测蒙版时向后续阶段传递气泡蒙版的逻辑。

### 字体字重与列表去重

- 修复部分日文字体同时包含传统家族名和排版家族名时，字体列表重复显示、字重漏项，以及加载顺序改变列表结果的问题；按实际字体内容合并重复入口，保留不同字重。
- 字体选择明确保存家族和样式，修复选中 H 等字重后实际渲染为默认 R 字重的问题；旧字体名称经实际字体核对后映射，保持预览与渲染选择一致。
- 字体目录新增、删除或原路径替换字体后，同步更新字体注册、列表和相关缓存，避免继续显示或使用旧字体信息。
