# Agent 开发约定

## 当前阶段

Agent 子系统处于开发和调试阶段。基础聊天、独立调试 UI 不等于完整漫画 Agent、工作区、工具或订阅登录已经交付。

## 改动边界

- 只实现用户当前明确要求的功能。保留现有实现，不主动进行额外重构、迁移、删除或扩大范围。
- 不把开发中的 Agent 功能写入项目更新日志，也不按正式发布功能宣传。
- 不主动新增、修改或运行测试，不执行整项目验证；需要验证时先遵循用户当次明确指示。不得把未执行的验证描述为通过。
- 不擅自修改现有主程序导航、页面接线或启动流程。独立调试 UI 与现有页面并存；除非用户要求，不移除已有入口。
- 独立调试入口为 `desktop_qt_ui/agent_debug.py`。在项目根目录运行：`uv run --no-sync desktop_qt_ui/agent_debug.py`。不要直接运行窗口组件文件。

## 实现与维护

- 使用 PydanticAI 原生模型适配器和执行接口，不自行重写模型执行循环。
- 当前后端使用 Responses API 原生流式输出，不静默降级到 Chat Completions；未按要求接入的工具、MCP、插件不预先实现。
- domain 定义消息契约，application 管理会话，providers 处理模型适配；Qt 只处理交互和异步事件，不把 widget 传入后端。
- 复用现有配置、异步服务和 UI 组件，不另造同职责框架。关闭窗口、停止或清空会话不得让旧响应回填；只有完整成功的轮次进入后续上下文。

## 调试与配置

- 保留独立聊天和请求体调试页面，后续调试能力在独立 UI 中按需增加。
- 请求体取自 SDK 实际序列化的请求，不伪造预览。未发请求时明确显示暂无请求。
- 调试 JSON 中图片 base64 只显示 MIME 类型、字节数和编码长度摘要；实际模型请求仍发送完整图片。调试视图不展示鉴权头，不把请求体写入日志或磁盘。
- 支持直接粘贴剪贴板图片、预览和移除待发送图片；使用框架原生图片内容传入模型。
- 按用户开发需求，将 API 地址、模型和 Key 保存在现有应用 `.env` 的独立 `AGENT_OPENAI_*` 配置中并自动恢复，不覆盖翻译器配置。
- `.env` 中 Key 是明文；界面保持密码遮罩。清空会话不删除连接配置，清空 Key 输入框清除已保存的 Key。聊天记录和图片仅保存在内存。
