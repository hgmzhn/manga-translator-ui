# 作品案例集（Case Studies）

> 这里收录**具体作品**的实战案例，用来说明各条规则是怎么来的。规则本身见 [style_and_pitfalls.md](style_and_pitfalls.md) 和 [mistranslation_checklist.md](mistranslation_checklist.md)。
> 处理**同一部作品**时，可以把这里的人名、术语、角色口吻直接当作参考；处理其他作品时**只借鉴方法，不要套用这里的具体译名或字体习惯**。
> 新作品的典型案例可以按同样格式追加到文末。

## 案例 A：《ソード・オラトリア》（地下城邂逅外传·剑姬神圣谭）第 15 卷

### A.1 OCR 误读错译

### A.2 语境错译
- **零代词**：芬恩对众人说 `リヴェリアにはお使いを頼んでいる`，接着说 `こんな朝早くから申し訳ないけどね`，意思是一大早就折腾里维莉亚很过意不去，不是对提问的蒂奥娜说“拜托你真抱歉”。
- **禁止句**：蕾娜刚夸白兔可爱就一刀秒杀，伯特吼 `言ってるそばから仕留めるんじゃねえ` → “别嘴上刚夸完转头就下死手啊！”
- **`ううん`**：`私以外知らないかもよ～？ ううん きっと知らないだろ～な～` → “不，肯定没人知道吧～”
- **`何もかもが違う`**：在列举了学者的四种假说之后 → “全错了”。
- **多义词**：蕾娜脸红说 `何だかベート・ローガの顔が上手く見れない` → “害羞得不敢正眼看伯特·罗卡的脸”。
- **添词撞车**：`#00 狼の遠吠えには四つの理由があると昔の学者は言ったらしい` 被加上“其中第一个”，和 `#01 一つ目は敵に対し…` 撞车。
- **倒装与腔调**：洛基的关西腔 `神に嘘の罪の告白とか無駄やっちゅーに` → `都说了跟神明 / 编假话认罪 / 是没有用的嘛`；`あれならとっくにうちの子らが片づけたわ` → `那玩意早就被 / 我家的孩子们 / 收拾掉啦`。
- **术语统一**：阿伊莎 / 艾夏的译名分裂。

### A.3 角色口吻与字体实测
- 伯特（`てめぇ / オレ / クソッタレ`）用硬派口语；乌拉诺斯、里维莉亚保持凝练威严；蒂奥娜、蕾娜保持灵动元气。
- `KAISHO_BRUSH`（重毛笔楷书）常见于凶狼伯特、芭婕、芮薇丝的压迫感低吼。
- `REISHO`（隶书）常见于乌拉诺斯、塔纳托斯的神谕，以及【汝，弓之——】这类魔法咏唱。
- `POP_CHISEL`（`ComicReggaeStd-B`）常见于崩溃质问和傲娇吐槽。

### A.4 版面实例
- **页眉刊头**：正文页顶部重复出现的 `ソード・オラトリア [15]`，删除并还原原画。
- **目录页**：右侧页码 `003..145`，逐行左对齐。
- **短吼放大**（原「图7」）：`ていっ` 占满大椭圆泡约 68% 高度，译成 `喝！` 后要放大到气室内高的 55%~65%。
- **断句实例**：`当上竞争率 / 超高的雄性的 / 老婆!!` `[5,6,3]`；`那个︙ / 如果方便的话︙ / 下次还能见面的话 / 这回要不要 / 去﹃下层﹄？` `[3,7,8,5,5]`。
- **Gate B 倒退实例**（原 `V14_013 #0/#1`，见 `tests/test_v14_closed_loop_hardening.py`）：高置信度 `MINCHO=1.00 Ryumin-Ultra` 的框（`FZCuSong-B09`）在视觉复核时被凭缩略图改回 `FZLanTingYuan-B-GBK`，被 `qa-diff` 拦截。这就是 `[LOCKED>=0.90]` 保护锁的由来。
