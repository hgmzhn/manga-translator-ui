# 日漫防错译核查手册（通用版）

> **第一原则：不要盲信 JSON 里的 `source_text`（OCR 文本）。**
> 初翻里离谱的错译，大部分不是模型不懂日语，而是竖排 OCR 先读错了假名、数字或断列，或者一个气泡被切成了乱序碎片，模型只能在错误输入上硬猜。剩下的大多来自脱离画面造成的主宾颠倒、否定漏译和多义词误选。
> 所以核查必须三步一起做：**`script-audit` 自动雷达 + 1.6x 原图切片核字 + `P001 → P_end` 结合分镜逐框通读。**
> 下面都是通用示例；具体作品的真实案例见 [case_studies.md](case_studies.md)。

## 一、OCR 误读引发的五类错译（必须看原图）

| 类别 | 原图真实日文 | OCR 常见误读 | 典型错译 ❌ | 正确译文 ✅ | 审计标签 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **1. 浊音 / 半浊音、形近假名** | `ブチのめされてぇのか？`<br>人名 `ケン` / `マリエッタ` | `プチのめされてえのか？`<br>`ケソ` / `マリエッツ` | *想被小小地玩弄吗？*<br>瞎造人名 *凯索* / *玛丽艾兹* | **想被老子揍扁吗？**<br>**阿健** / **玛丽埃塔**（以术语表为准） | `suspect_ocr_corruption_mistranslation`<br>`suspect_ocr_glossary_typo` |
| **2. 竖排纵中横的等级 / 数字** | `大半が Lv.2`、`唯一の Lv.3`<br>`1秒毎に`、`四つの理由` | `大半かい２`、`唯一の以３`<br>`1秒甸に`、`ヨつの理由` | *大半都会…*（漏掉等级，还补了省略号） | **大半都只有 Lv.2**、**唯一的 Lv.3**<br>**每一秒**、**四个理由** | `translation_number_mismatch`<br>`invented_ellipsis_truncated_translation` |
| **3. 一个气泡被切碎、顺序打乱** | `傷をこさえるより死ぬ方がマシだってか！` | `#11 傷を死ぬ方が` / `#12 こさえるよい` / `#13 マシだってか！` | *受伤总比死…*（意思完全反了） | 合并成一框重译：**难不成你们想说，比起受点伤还不如直接去死吗！？** | `same_bubble_split_regions`（`error`） |
| **4. 尾列截断 + 伪造省略号** | `はいはーい！○○はー！？（内容についてじゃないけど！）` | `はいはー○○はー！内容についてし` | *是的是的 / ○○是 / 关于内容的…* | **我举手——！○○人呢——！？**（框外小字：**虽然问的不是刚才的内容！**） | `invented_ellipsis_truncated_translation` |
| **5. 振假名混进正文或丢失** | `ボーイ・ミーツ・ガール`<br>`本気(マジ)` 这类“汉字+异读注音” | `ボーイミーツガ`<br>`本マジ気` | *男孩遇见*（漏译“女孩”）<br>*本玛吉气* | **男孩遇见女孩**<br>**认真的（动真格）**：按语境取义，必要时保留注音双关（括注或 ruby） | `low_ocr_confidence` |

**常见形近混淆**：`ン/ソ`、`シ/ツ`、`タ/夕`、`カ/力`、`ロ/口`、`ニ/二`、`へ/ヘ`、`ハ/八`、`エ/工`、`ー/一`、`ぱ/ば`、`プ/ブ`、`ペ/ベ`。人名和术语只要出现这些字形，一律对照原图和术语表核实。

> [!CAUTION]
> **用 `mtui_merge_regions` 合并碎框时**，禁止把各碎框的旧译文直接拼起来。必须先按右起竖排顺序，从原图读出完整日文原句，再整句重译。

## 二、必须结合画面才能发现的语境错译

### 1. 零代词导致指代错乱
- **原因**：日语很少写出「你 / 我 / 他 / 她」，纯文本模型默认补成“你”或“我”。
- **通用例**：角色 A 对众人说 `Bにはお使いを頼んでいる`（*我已经拜托 B 去跑腿了*），紧接着说 `こんな朝早くから申し訳ないけどね`。这里是在说**一大早就折腾 B（她）很过意不去**，不是对眼前提问的 C 说 ❌ *“这么早还拜托你，真抱歉”*。
- **怎么查**：译文里出现人称代词时，看气泡尾巴指向谁、说话人在看谁、上一句的话题中心是谁。

### 2. 禁止、否定、反讽的正反颠倒（`negation_or_prohibition_drop_suspect`）
- **`～んじゃねえ` / `～るなよ`** 是严厉禁止：`言ってるそばから仕留めるんじゃねえ` → ✅ **“别嘴上刚夸完转头就下死手啊！”**（❌ 漏掉“别”）
- **句首 `ううん` 是否定**（“不 / 才不是”），`うん` 才是“嗯”。
- **反驳型 `何もかもが違う`** → ✅ **“全错了 / 根本不是那么回事”**（❌ *“一切都变了”*）
- **`～より…方がマシだってか！`** 是反问讽刺。
- **高频句式速查**：

| 句式 | 正确方向 |
|---|---|
| `～わけじゃない / ～わけではない` | 并不是… / 未必…（别漏掉句尾否定） |
| `～どころか` | 非但没有…反而… |
| `～に決まってる / ～に違いない` | 肯定是… |
| `～しかない / ～ほかない` | 只能… |
| `～てたまらない / ～てしょうがない` | …得不得了（是肯定强调，不是否定） |
| `嫌いじゃない / 悪くない` | 倒也不讨厌 / 还不错 |

### 3. 可能态与多义词：看表情选义
- 脸红捂胸说 `顔が上手く見れない` → ✅ **“害羞得不敢正眼看他的脸”**（❌ *“看不清他的脸”*）
- `甘い`：战斗或说教时是“太天真 / 下手太软”，吃东西时才是“甜”。
- `やる / 殺る`：干掉 / 动手 / 交给我。
- `首`：脑袋 / 开除。
- `邪魔する`：上门时是“打扰了”，战斗中是“碍事”。
- `いい加減にしろ`：适可而止吧 / 够了没有！

### 4. 无中生有添词，与相邻气泡撞车
- **通用例**：`#00 …には四つの理由があるらしい`，初翻在末尾擅自加了“其中第一个”，而 `#01` 原文正是 `一つ目は…`，结果同一页连读两次“第一个”。
- **怎么查**：通读同页相邻的框，看译文首尾有没有提前翻了下一框的内容，或者把上下气室的连接词重复翻译。

### 5. 日式句尾倒装与违和腔调（`inverted_japanese_calque_syntax`）
- 句尾的 `～っちゅーに / ～ってば / ～って言ってるだろ` 要**提到中文句首**：
  `神に嘘の罪の告白とか無駄やっちゅーに…` ❌ `跟神明 / 编假话认罪 / 都说了没用嘛…`（`[3,5,7]` 倒三角）→ ✅ `都说了跟神明 / 编假话认罪 / 是没有用的嘛`（`[6,5,6]`）
- 关西腔、轻快口吻用自然的句尾语气词，不要用生硬的北方儿化音：
  `あれならとっくにうちの子らが片づけたわ` ❌ `那玩意儿 / 早就被我家的孩子们 / 收拾掉了`（`[4,9,4]`）→ ✅ `那玩意早就被 / 我家的孩子们 / 收拾掉啦`（`[6,6,4]`）

### 6. 专有名词、人设口吻、术语统一（`glossary_term_mismatch`）
- 同一角色在同一卷里不能前后译名不一致（例如前面叫“莉莉安”，后面变成“莉莉娅”）。首次确定译名就写进 `mtui_manage_glossary`。
- 按人设调整口吻：粗犷角色（`てめぇ / オレ / クソッタレ`）用地道的硬派口语；神明、王族保持凝练威严；元气少女保持灵动。避免所有人都是同一种书面翻译腔。
