# 优化最近操作列表显示格式

## 问题描述

**现象**：
- 最近操作列表显示冗长的作品名称
- 作品名被截断，看不清完整信息
- 重复选择相同作品组合时，会产生多条重复记录
- 无法快速了解操作的统计信息（几个作品、多少章、章节范围）

**示例**（修改前）：
```
I Became an Apartment Security Manager Raw, 值...
11-24 20:30  ·  10章

I Became an Apartment Security Manager Raw, 值...
11-24 20:25  ·  10章

I Became an Apartment Security Manager Raw, 值...
11-24 20:20  ·  10章
```

---

## 解决方案

### 核心改进

#### 1. 不显示作品名，改为显示统计信息
- **单个作品**：只显示章节数，如 `10章`
- **多个作品**：显示作品数和章节数，如 `3个作品, 25章`

#### 2. 添加章节范围显示
- 自动计算选中章节的范围，如 `Ch.1-Ch.10`
- 如果只有一个章节，显示 `Ch.5`
- 如果无法提取章节号，显示章节总数

#### 3. 去除重复记录
- 保存新操作时，自动删除相同作品组合的旧记录
- 只保留最新的一条记录

## 显示格式

### 新格式示例

**单个作品**：
```
10章
11-24 20:30  ·  Ch.1-Ch.10
```

**多个作品**：
```
3个作品, 25章
11-24 20:30  ·  Ch.1-Ch.25
```

**只有时间**：
```
10章
11-24 20:30
```

### 格式说明

**第一行**：统计信息
- 格式：`{作品数}个作品, {章节数}章` 或 `{章节数}章`
- 简洁明了，不再显示冗长的作品名

**第二行**：时间和章节范围
- 格式：`{时间}  ·  {章节范围}`
- 时间：`MM-DD HH:mm` 格式
- 章节范围：`Ch.X-Ch.Y` 或 `Ch.X`

## 技术实现

### 1. 计算章节范围

新增 `_calculate_chapter_range()` 方法：

```python
def _calculate_chapter_range(self, chapter_names: List[str]) -> str:
    """计算章节范围，如 Ch.1-Ch.10"""
    if not chapter_names:
        return ""
    
    import re
    # 提取章节号
    chapter_numbers = []
    for name in chapter_names:
        # 尝试从章节名中提取数字
        match = re.search(r'(\d+)', name)
        if match:
            chapter_numbers.append(int(match.group(1)))
    
    if not chapter_numbers:
        # 无法提取数字，返回章节数量
        return f"{len(chapter_names)}章"
    
    chapter_numbers.sort()
    min_ch = chapter_numbers[0]
    max_ch = chapter_numbers[-1]
    
    if min_ch == max_ch:
        return f"Ch.{min_ch}"
    else:
        return f"Ch.{min_ch}-{max_ch}"
```

**工作原理**：
1. 遍历所有章节名称
2. 使用正则表达式提取第一个数字（章节号）
3. 排序后取最小和最大值
4. 格式化为 `Ch.X-Ch.Y`

### 2. 保存时去重

修改 `_save_recent_works()` 方法：

```python
# 去重：删除相同作品组合的旧记录
work_set = set(work_list)
recent_operations = [
    op for op in recent_operations
    if set(op.get('works', [])) != work_set
]

# 将新操作添加到列表开头
recent_operations.insert(0, operation)
```

**去重逻辑**：
1. 将新操作的作品列表转为集合
2. 遍历现有操作，删除作品集合相同的旧记录
3. 将新操作插入到列表开头

### 3. 优化显示逻辑

修改 `_load_recent_works()` 方法：

```python
# 第一行：统计信息（N个作品 M章）
works = operation.get('works', [])
chapter_count = operation.get('chapter_count', 0)
work_count = len(works)

if work_count == 1:
    summary_text = f"{chapter_count}章"
else:
    summary_text = f"{work_count}个作品, {chapter_count}章"

# 第二行：时间 + 章节范围
time_str = operation.get('time', '')
chapter_range = operation.get('chapter_range', '')

if time_str and chapter_range:
    detail_text = f"{time_str}  ·  {chapter_range}"
elif time_str:
    detail_text = time_str
elif chapter_range:
    detail_text = chapter_range
else:
    detail_text = "历史记录"

# 组合显示
display_text = f"{summary_text}\n{detail_text}"
```

## 注意事项

### 1. 章节号提取
- 使用正则表达式 `r'(\d+)'` 提取第一个数字
- 适用于大部分章节命名格式
- 特殊格式可能无法正确提取

### 2. 去重逻辑
- 基于作品列表的集合比较
- 只要作品组合相同就认为是重复（不考虑章节）
- 这样可以避免同一作品的多次操作产生重复记录

### 3. 向后兼容
- 旧数据没有 `chapter_range` 字段
- 显示逻辑会自动降级
- 不会影响现有功能
