# 高级文件夹根目录保存修复

## 🐛 问题描述

用户反馈：每次打开"高级文件夹"对话框时，根目录没有被记忆，需要重新选择。

---

## 🔍 问题原因

### 原有保存逻辑的缺陷

**之前的代码：**
```python
def show_advanced_folder_dialog(parent=None, start_dir: str = "") -> Optional[List[str]]:
    dialog = AdvancedFolderDialog(parent, start_dir)
    
    if dialog.exec() == QDialog.DialogCode.Accepted:
        selected = dialog.get_selected_chapters()
        
        if selected:
            # 只在这里保存路径 ⚠️
            settings.setValue("last_dir", dialog.root_path_edit.text())
            return selected
    
    return None
```

### 问题分析

根目录**仅在以下情况保存**：
- ✅ 点击"确定"
- ✅ **且**有选中章节

**不保存的情况（问题所在）：**
- ❌ 点击"取消"
- ❌ 点击"确定"但未选中章节
- ❌ 用户修改了根目录但没有进行选择操作

### 实际场景举例

**场景1：** 用户想查看不同根目录的内容
1. 打开对话框，修改根目录为 `D:\漫画2`
2. 扫描并查看作品列表
3. 没有选择任何章节，直接点击"取消"
4. 下次打开对话框 → ❌ **根目录丢失，恢复到旧路径**

**场景2：** 用户修改根目录后发现无内容
1. 修改根目录但该目录没有作品
2. 点击"取消"退出
3. 下次打开 → ❌ **根目录丢失**

---

## ✅ 修复方案

### 统一在对话框关闭时保存

无论用户点击"确定"还是"取消"，只要根目录有效，就应该保存。

### 修复后的代码

#### 1. 添加 `_save_root_path()` 方法
```python
def _save_root_path(self):
    """保存根目录路径"""
    settings = QSettings("MangaTranslator", "AdvancedFolder")
    root_path = self.root_path_edit.text()
    if root_path and os.path.isdir(root_path):
        settings.setValue("last_dir", root_path)
```

#### 2. 在 `accept()` 和 `reject()` 中调用
```python
def accept(self):
    """确定按钮点击"""
    self._save_column_widths()
    self._save_root_path()  # ✅ 保存根目录
    super().accept()

def reject(self):
    """取消按钮点击"""
    self._save_column_widths()
    self._save_root_path()  # ✅ 保存根目录
    super().reject()
```

#### 3. 移除重复的保存逻辑
```python
def show_advanced_folder_dialog(parent=None, start_dir: str = "") -> Optional[List[str]]:
    dialog = AdvancedFolderDialog(parent, start_dir)
    
    if dialog.exec() == QDialog.DialogCode.Accepted:
        selected = dialog.get_selected_chapters()
        if selected:
            # ✅ 移除了重复的 settings.setValue()
            return selected
    
    return None
```

## 🔧 技术细节

### 保存时机
- `accept()`：用户点击"确定"
- `reject()`：用户点击"取消"或关闭窗口

### 安全检查
```python
if root_path and os.path.isdir(root_path):
    settings.setValue("last_dir", root_path)
```

**只在以下情况保存：**
- ✅ 路径不为空
- ✅ 路径是有效的目录

**不保存的情况：**
- ❌ 空路径
- ❌ 无效路径（不存在的目录）
