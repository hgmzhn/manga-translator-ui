# 智能拖拽选择：正向累加、反向取消

## 功能说明

实现智能拖拽选择逻辑：
- **正向拖拽**：拖拽未勾选的章节 → 自动勾选（累加）
- **反向拖拽**：拖拽已勾选的章节 → 自动取消（清除）
- **自动判断**：根据拖拽区域内已勾选项目的比例自动判断意图

---

## 核心逻辑

### 判断规则
```python
# 分离当前选中的项目
selected_and_checked = current & checked      # 选中且已勾选
selected_and_unchecked = current - checked   # 选中但未勾选

# 判断操作意图
if len(selected_and_checked) >= len(selected_and_unchecked):
    取消(selected_and_checked)  # 反向拖拽
else:
    勾选(selected_and_unchecked)  # 正向拖拽
```

### 判断依据
- **已勾选项 ≥ 未勾选项**：认为是反向拖拽，取消勾选
- **未勾选项 > 已勾选项**：认为是正向拖拽，累加勾选

---

## 使用示例

### 场景1：正向累加
```
1. 拖拽 "第1-3话"（未勾选）    → 勾选 1,2,3
2. 拖拽 "第5-6话"（未勾选）    → 勾选 5,6（保留1,2,3）
结果：已选中 1,2,3,5,6
```

### 场景2：反向取消
```
1. 已选中：1,2,3,5,6
2. 拖拽 "第5-6话"（已勾选）    → 取消 5,6
结果：已选中 1,2,3
```

### 场景3：混合拖拽
```
1. 已选中：1,2,3
2. 拖拽 "第2-5话"（2,3已勾选，4,5未勾选）
   → 已勾选2个，未勾选2个，相等
   → 判定为反向拖拽，取消 2,3
结果：已选中 1
```
