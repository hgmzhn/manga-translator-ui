# 优化智能选择按钮交互逻辑

## 🎯 优化内容

### 1. 按钮宽度统一
- 所有按钮统一宽度：120px
- 所有按钮统一高度：30px
- 使用 `setMinimumSize(120, 30)`

### 2. 菜单交互优化
- **切换菜单选项**：只打勾，不执行
- **点击主按钮**：才执行当前模式的选择
- 分离"选择模式"和"执行操作"两个动作

### 2. 菜单交互优化

#### 菜单项连接

```python
# 选项1：选择所有最新章节
self.action_latest.triggered.connect(
    lambda: self.set_smart_select_mode("latest", execute=False)  # ✅ execute=False 只打勾不执行
)

# 选项2：选择1小时内下载的最新话
self.action_recent_hour.triggered.connect(
    lambda: self.set_smart_select_mode("recent_hour", execute=False)  # ✅ execute=False 只打勾不执行
)
```

#### 模式设置方法

```python
def set_smart_select_mode(self, mode: str, execute: bool = True):
    """设置智能选择模式并保存
    
    Args:
        mode: 模式名称 ('latest' 或 'recent_hour')
        execute: 是否立即执行选择，默认True
    """
    self.smart_select_mode = mode
    
    # 更新菜单项的勾选状态
    self.action_latest.setChecked(mode == "latest")
    self.action_recent_hour.setChecked(mode == "recent_hour")
    
    # 保存选择
    settings = QSettings("MangaTranslator", "AdvancedFolder")
    settings.setValue("smart_select_mode", mode)
    
    mode_names = {"latest": "选择所有最新章节", "recent_hour": "选择1小时内下载的最新话"}
    self._log(f"✓ 智能选择模式: {mode_names.get(mode, mode)}")
    
    # 根据execute参数决定是否立即执行
    if execute:  # ✅ 只有 execute=True 时才执行
        self.execute_smart_select()
```

## 📊 交互对比

### 优化前

| 操作 | 行为 | 问题 |
|------|------|------|
| **点击菜单选项** | 切换打勾 + 立即执行 | ❌ 可能误操作 |
| **点击主按钮** | 执行选择 | ✅ 正常 |

**问题**：用户只想切换模式，但会立即执行，可能不是用户想要的时机。

### 优化后

| 操作 | 行为 | 优势 |
|------|------|------|
| **点击菜单选项** | 只切换打勾，不执行 | ✅ 用户可以先选模式 |
| **点击主按钮** | 执行当前模式 | ✅ 用户主动触发 |

**优势**：
- 用户可以先切换模式，再决定何时执行
- 避免误操作
- 交互更加可控

## 💡 设计理念

### 1. 视觉一致性

**问题**：按钮宽度不一致，看起来不整齐

**解决**：统一设置 `setMinimumSize(120, 30)`

**效果**：
```
⚡ 智能选择 ▼  120px × 30px
全选章节        120px × 30px
取消全选        120px × 30px
```

### 2. 操作可预测性

**问题**：点击菜单选项会立即执行，可能不是用户想要的

**解决**：分离"选择模式"和"执行操作"

**效果**：
- 点击菜单 = 选择模式（只打勾）
- 点击按钮 = 执行操作（真正执行）

### 3. 用户控制权

**原则**：让用户决定何时执行，而不是自动执行

**实现**：
- 菜单：`execute=False`（不执行）
- 按钮：`execute_smart_select()`（执行）
