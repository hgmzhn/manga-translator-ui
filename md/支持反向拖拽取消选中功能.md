# 支持反向拖拽取消选中功能

## 🎯 功能描述

在高级文件夹的章节列表中，支持通过鼠标拖拽来选中或取消选中章节，实现双向操作。

---

## 🐛 问题描述

**修复前的行为：**
- ✅ 可以拖拽鼠标选中多个章节
- ❌ **不能反向拖拽取消选中**
- 用户体验不完整

**用户反馈：**
> "现在正拖拽鼠标选择，怎么没有反拖拽鼠标取消"

---

## ✅ 修复方案

### 核心思路

**双向同步**：选中状态 ↔ 复选框状态

1. **正向拖拽**：选中项 → 勾选复选框
2. **反向拖拽**：取消选中 → 取消勾选复选框

### 实现逻辑

#### 修复前（单向）

```python
def on_selection_changed(self):
    selected_items = self.title_tree.selectedItems()
    
    # 只处理选中的项，勾选复选框
    for item in selected_items:
        if is_chapter(item):
            item.setCheckState(0, Qt.CheckState.Checked)  # ✅ 勾选
    
    # ❌ 问题：没有处理未选中的项，不会取消勾选
```

#### 修复后（双向）

```python
def on_selection_changed(self):
    selected_items = self.title_tree.selectedItems()
    selected_paths = set()
    
    # 收集所有选中的章节路径
    for item in selected_items:
        if is_chapter(item):
            selected_paths.add(item.path)
    
    # 遍历所有章节项，同步复选框状态
    for all_item in all_chapters:
        should_be_checked = all_item.path in selected_paths
        
        if should_be_checked:
            all_item.setCheckState(0, Qt.CheckState.Checked)    # ✅ 勾选
        else:
            all_item.setCheckState(0, Qt.CheckState.Unchecked)  # ✅ 取消勾选
```

## 🔧 技术实现

### 1. 修改 `on_selection_changed` 方法

**新增逻辑：**
- 收集所有选中项的路径到集合
- 遍历所有章节项
- 根据是否在集合中，设置或取消复选框

```python
def on_selection_changed(self):
    """选择改变时同步到复选框（支持鼠标拉取多选和反向取消）"""
    self.title_tree.itemChanged.disconnect(self.on_item_changed)
    
    try:
        # 获取当前选中的项目
        selected_items = self.title_tree.selectedItems()
        selected_paths = set()
        
        # 收集所有选中的章节路径
        for item in selected_items:
            path = item.data(0, Qt.ItemDataRole.UserRole)
            if path and isinstance(path, str) and os.path.isdir(path):
                selected_paths.add(path)
        
        # 遍历所有章节项，同步复选框状态
        root = self.title_tree.invisibleRootItem()
        self._sync_checkboxes_recursive(root, selected_paths)
        
    finally:
        self.title_tree.itemChanged.connect(self.on_item_changed)
        self._update_selection_count()
```

### 2. 新增 `_sync_checkboxes_recursive` 方法

递归遍历所有章节项，同步复选框状态：

```python
def _sync_checkboxes_recursive(self, parent: QTreeWidgetItem, selected_paths: set):
    """递归同步复选框状态"""
    for i in range(parent.childCount()):
        item = parent.child(i)
        path = item.data(0, Qt.ItemDataRole.UserRole)
        
        if path and isinstance(path, str) and os.path.isdir(path):  # 是章节项
            # 根据是否在选中集合中，设置复选框状态
            should_be_checked = path in selected_paths
            current_state = item.checkState(0)
            
            if should_be_checked and current_state != Qt.CheckState.Checked:
                item.setCheckState(0, Qt.CheckState.Checked)
            elif not should_be_checked and current_state == Qt.CheckState.Checked:
                item.setCheckState(0, Qt.CheckState.Unchecked)
        
        # 递归处理子项
        if item.childCount() > 0:
            self._sync_checkboxes_recursive(item, selected_paths)
```

## 💡 技术细节

### 为什么使用 Set 集合？

```python
selected_paths = set()
```

**优势：**
1. **快速查找**：`path in selected_paths` 是 O(1) 操作
2. **去重**：自动去除重复路径
3. **高效**：处理大量章节时性能更好

### 为什么需要递归？

```python
self._sync_checkboxes_recursive(root, selected_paths)
```

**原因：**
- 章节可能在多层嵌套结构中
- 三层结构：作品 → 来源 → 章节
- 需要遍历所有层级的章节项

### 信号断开/重连

```python
self.title_tree.itemChanged.disconnect(self.on_item_changed)
try:
    # 修改复选框状态
finally:
    self.title_tree.itemChanged.connect(self.on_item_changed)
```

**目的：**
- 避免递归触发
- 修改复选框时不触发 `on_item_changed`
- 完成后统一更新统计
