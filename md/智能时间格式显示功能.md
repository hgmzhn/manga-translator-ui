# 智能时间格式显示功能

## 🎯 功能描述

为高级文件夹的章节修改时间添加智能格式化显示，根据时间差自动选择最合适的显示格式。

---

## 📅 时间格式规则

| 时间范围 | 显示格式 | 示例 | 说明 |
|---------|---------|------|------|
| **今天** | `HH:MM` | `14:30` | 只显示时分，省略日期 |
| **今年** | `MM-DD HH:MM` | `11-23 14:30` | 显示月日时分，省略年份 |
| **往年** | `YYYY-MM-DD` | `2024-11-23` | 显示完整日期，省略时间 |

---

## 💡 设计理念

### 信息密度优化

根据时间距离调整显示详细程度：

1. **今天的文件**
   - 用户最关心具体时间
   - 日期信息冗余（都是今天）
   - ✅ 只显示时分：`14:30`

2. **今年的文件**
   - 需要知道是哪一天
   - 年份信息冗余（都是今年）
   - ✅ 显示月日时分：`11-23 14:30`

3. **往年的文件**
   - 需要知道具体年份
   - 时间信息不重要（已经很久了）
   - ✅ 只显示年月日：`2024-11-23`

### 用户体验优势

| 优势 | 说明 |
|------|------|
| **节省空间** | 列宽更紧凑，显示更多内容 |
| **易于阅读** | 去除冗余信息，重点突出 |
| **符合直觉** | 符合人类对时间的认知习惯 |
| **快速识别** | 一眼看出是今天、最近还是很久前 |

## 🔧 技术实现

### 核心函数

```python
def _format_time_smart(self, timestamp: float) -> str:
    """智能格式化时间
    
    规则：
    - 今天：HH:MM (如 14:30)
    - 今年：MM-DD HH:MM (如 11-23 14:30)
    - 往年：YYYY-MM-DD (如 2024-11-23)
    """
    try:
        file_time = datetime.fromtimestamp(timestamp)
        now = datetime.now()
        
        # 判断是否是今天
        if file_time.date() == now.date():
            return file_time.strftime("%H:%M")
        
        # 判断是否是今年
        elif file_time.year == now.year:
            return file_time.strftime("%m-%d %H:%M")
        
        # 往年
        else:
            return file_time.strftime("%Y-%m-%d")
    except:
        return "未知"
```

### 应用位置

在两个地方应用智能格式化：

#### 1. 多来源章节显示
```python
# 显示修改时间而不是路径（智能格式）
try:
    mtime = os.path.getmtime(chapter['path'])
    time_str = self._format_time_smart(mtime)  # ✅ 智能格式化
    chapter_item.setText(2, time_str)
except:
    chapter_item.setText(2, "未知")
```

#### 2. 单来源章节显示
```python

    child_item.setText(2, time_str)
except:

```

## 📊 显示效果对比

### 修复前（固定格式）

```
作品/章节              来源    最新话/数量          状态
────────────────────────────────────────────────────
小说名                源1     2024-11-24 14:30    ✓
├─ 第1话                      2024-11-23 18:30
├─ 第2话                      2024-11-24 14:30
└─ 第3话                      2023-12-15 10:20
```

**问题**：
- 所有时间都显示完整格式
- 信息冗余（今天的也显示年月日）
- 占用列宽较大

### 修复后（智能格式）

```
作品/章节              来源    最新话/数量          状态
────────────────────────────────────────────────────
小说名                源1     14:30               ✓
├─ 第1话                      11-23 18:30
├─ 第2话                      14:30              ← 今天，只显示时间
└─ 第3话                      2023-12-15         ← 往年，不显示时间
```

**优势**：
- ✅ 今天的章节一目了然（14:30）
- ✅ 最近的章节显示日期和时间（11-23 18:30）
- ✅ 旧章节只显示日期（2023-12-15）
- ✅ 列宽更紧凑


## 🔍 边界情况处理

### 跨年情况

**场景**：当前是 2025-01-01，文件是 2024-12-31

```python
# 文件时间：2024-12-31 23:59
# 当前时间：2025-01-01 00:01

file_time.year == now.year  # False
# 结果：显示 "2024-12-31"（往年格式）
```

**合理性**：虽然只差2分钟，但跨年了，显示年份更清晰。

### 时区问题

使用 `datetime.now()` 和 `datetime.fromtimestamp()`，都使用系统本地时区，保持一致。

### 异常处理

```python
try:
    # 格式化逻辑
except:
    return "未知"
```

任何异常都返回"未知"，确保程序不会崩溃。
