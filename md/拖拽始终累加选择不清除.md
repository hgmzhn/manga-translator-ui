# 拖拽始终累加选择不清除

## 问题描述

**现象**：
- 用户先拖拽选择1-3话
- 不按 Ctrl，直接拖拽选择5-6话
- 之前选中的1-3话被自动取消勾选
- 只保留最后选择的5-6话

**期望**：
- 即使不按 Ctrl 键，拖拽选择也应该累加
- 保留之前所有勾选的章节
- 只能通过手动点击复选框来取消选择

---

## 原因分析

### QTreeWidget 的默认行为
在 `ExtendedSelection` 模式下，QTreeWidget 的行为是：
- **不按修饰键**：清除之前的选择，只保留当前选择
- **按 Ctrl 键**：追加选择，保留之前的选择
- **按 Shift 键**：范围选择

### 之前的同步逻辑
```python
# 计算变化
newly_selected = current_selected_paths - self.last_selected_paths
newly_deselected = self.last_selected_paths - current_selected_paths  # ❌ 问题在这里

# 同步复选框
self._toggle_checkboxes_for_paths(root, newly_selected, Checked)
self._toggle_checkboxes_for_paths(root, newly_deselected, Unchecked)  # ❌ 会取消之前的勾选
```

**问题**：
- 当用户不按 Ctrl 直接拖拽时，QTreeWidget 会清除之前的选择
- `newly_deselected` 会包含之前的所有选择
- 导致之前勾选的复选框被取消

---

## 解决方案

### 核心思路
**将复选框状态作为唯一标准，拖拽只负责累加，不负责清除**

1. **只处理新增选择**：只勾选新选中的项目
2. **保留已勾选状态**：不取消任何已勾选的项目
3. **手动取消**：用户只能通过点击复选框来取消选择

### 新逻辑

#### 1. 新增方法：获取所有已勾选路径
```python
def _get_all_checked_paths(self, parent: QTreeWidgetItem) -> set:
    """获取所有已勾选的章节路径（递归）"""
    checked_paths = set()
    for i in range(parent.childCount()):
        item = parent.child(i)
        path = item.data(0, Qt.ItemDataRole.UserRole)
        
        if path and isinstance(path, str) and os.path.isdir(path):
            if item.checkState(0) == Qt.CheckState.Checked:
                checked_paths.add(path)
        
        # 递归处理子项
        if item.childCount() > 0:
            checked_paths.update(self._get_all_checked_paths(item))
    
    return checked_paths
```

#### 2. 修改选择同步逻辑
```python
def on_selection_changed(self):
    """选择改变时同步到复选框（拖拽始终累加选择）"""
    try:
        # 获取当前选中的章节路径
        current_selected_paths = set()
        for item in selected_items:
            path = item.data(0, Qt.ItemDataRole.UserRole)
            if path and isinstance(path, str) and os.path.isdir(path):
                current_selected_paths.add(path)
        
        # 获取所有已勾选的章节路径
        root = self.title_tree.invisibleRootItem()
        checked_paths = self._get_all_checked_paths(root)
        
        # 计算新增选中的项目（排除已经勾选的）
        newly_selected = current_selected_paths - checked_paths
        
        # 只勾选新选中的项目，不取消已勾选的项目
        if newly_selected:
            self._toggle_checkboxes_for_paths(root, newly_selected, Qt.CheckState.Checked)
        
        # 更新上一次的选择状态
        self.last_selected_paths = current_selected_paths.copy()
    finally:
        # 重新连接信号并更新统计
        ...
```

### 对比

#### 旧逻辑
```python
# 计算新增和取消
newly_selected = current - last      # 新选中的
newly_deselected = last - current    # 被取消的 ❌

# 同步复选框
勾选(newly_selected)
取消(newly_deselected)  # ❌ 会清除之前的选择
```

#### 新逻辑
```python
# 只计算新增
checked = 获取所有已勾选()
newly_selected = current - checked   # 新选中且未勾选的

# 只勾选，不取消
勾选(newly_selected)  # ✅ 只累加
```

## 功能特性

### ✅ 累加选择
- **无需 Ctrl**：直接拖拽即可累加选择
- **保留状态**：之前勾选的章节始终保留
- **简化操作**：不需要记住是否按住 Ctrl

### ✅ 手动取消
- **点击复选框**：取消勾选单个章节
- **取消全选按钮**：一键清除所有选择
- **精确控制**：用户完全掌控选择状态

### ✅ 反向拖拽
- **支持保留**：反向拖拽取消选择时，之前的勾选也会保留
- **行为一致**：所有拖拽操作都是累加模式

## 技术细节

### 状态管理
- **复选框状态**：唯一的选择标准
- **视觉选中**：仅用于操作反馈，不影响复选框
- **持久化**：只保存复选框状态

### 性能优化
- **集合操作**：使用 set 进行路径比较，O(n) 复杂度
- **递归遍历**：只遍历一次获取所有勾选路径
- **增量更新**：只处理新增的项目，不重复处理已勾选项

### 兼容性
- **向后兼容**：不影响之前的功能
- **用户习惯**：简化操作，更符合直觉
- **一致性**：所有拖拽行为统一为累加模式
