# 修复高级文件夹根目录被主程序覆盖问题

## 🐛 问题描述

用户报告：
1. 在高级文件夹中设置根目录为 `D:\漫画\MuMu共享文件夹\mihon\downloads`
2. 日志显示 "✓ 已保存根目录: D:\漫画\MuMu共享文件夹\mihon\downloads"
3. 但退出重新打开后，根目录变成了 `D:\漫画\未翻译\1`

---

## 🔍 问题原因分析

### 两套独立的"最后打开目录"系统

#### 1. 主程序的 `last_open_dir`
- **存储位置**：`app.last_open_dir`（主配置）
- **用途**：记录主程序"添加文件夹"功能的最后路径
- **值**：`D:\漫画\未翻译\1`（用户最后用主程序打开的路径）

#### 2. 高级文件夹的 `last_dir`
- **存储位置**：`QSettings("MangaTranslator", "AdvancedFolder")`
- **用途**：记录高级文件夹对话框的根目录
- **值**：`D:\漫画\MuMu共享文件夹\mihon\downloads`（用户在高级文件夹中设置的）

### 冲突发生的流程

```python
# app_logic.py 中的 open_advanced_folder 方法
def open_advanced_folder(self):
    last_dir = self.get_last_open_dir()  # ❌ 获取主程序的 last_open_dir
    
    selected_chapters = show_advanced_folder_dialog(
        parent=None,
        start_dir=last_dir  # ❌ 传入主程序的路径，覆盖了高级文件夹自己的设置
    )
```

**问题**：主程序的 `last_dir` 作为 `start_dir` 传入，覆盖了高级文件夹自己保存的根目录。

---

## ✅ 修复方案

### 核心思路

**让高级文件夹使用自己的根目录设置，不受主程序影响。**

### 修复代码

**修复前：**
```python
def open_advanced_folder(self):
    """打开高级文件夹对话框，支持三层目录结构批量选择章节"""
    last_dir = self.get_last_open_dir()  # ❌ 获取主程序的路径
    
    from widgets.advanced_folder_panel import show_advanced_folder_dialog
    
    selected_chapters = show_advanced_folder_dialog(
        parent=None,
        start_dir=last_dir  # ❌ 传入主程序的路径
    )
```

**修复后：**
```python
def open_advanced_folder(self):
    """打开高级文件夹对话框，支持三层目录结构批量选择章节"""
    from widgets.advanced_folder_panel import show_advanced_folder_dialog
    
    # 不传入start_dir，让高级文件夹使用自己保存的根目录设置
    selected_chapters = show_advanced_folder_dialog(
        parent=None,
        start_dir=""  # ✅ 空字符串，让对话框使用自己的last_dir
    )
```

### 工作原理

当 `start_dir=""` 时，`show_advanced_folder_dialog` 函数会：

```python
def show_advanced_folder_dialog(parent=None, start_dir: str = "") -> Optional[List[str]]:
    settings = QSettings("MangaTranslator", "AdvancedFolder")
    if not start_dir:  # ✅ start_dir为空，使用自己保存的路径
        saved_dir = settings.value("last_dir", "")
        if saved_dir and os.path.isdir(saved_dir):
            start_dir = saved_dir  # ✅ 使用高级文件夹自己的根目录
        else:
            start_dir = str(Path.home() / "Downloads")
```

## 🎯 设计理念

### 功能独立性原则

**高级文件夹**和**主程序添加文件夹**是两个不同的功能，应该有独立的配置：

| 功能 | 用途 | 配置存储 | 应该独立 |
|------|------|----------|----------|
| **主程序添加文件夹** | 添加单个文件夹/文件 | `app.last_open_dir` | ✅ |
| **高级文件夹** | 批量管理三层结构 | `AdvancedFolder.last_dir` | ✅ |

**修复前**：两个功能共享路径，导致相互干扰
**修复后**：两个功能完全独立，各自记忆各自的路径

---

## 💡 技术细节

### 为什么不删除 `start_dir` 参数？

保留 `start_dir` 参数是为了：
1. **向后兼容**：其他地方可能调用这个函数
2. **灵活性**：未来可能需要从外部指定初始路径
3. **最佳实践**：传入空字符串明确表达"使用默认值"的意图

### 路径优先级

`show_advanced_folder_dialog` 的路径选择优先级：

```
1. start_dir（如果提供且有效）
   ↓
2. QSettings("AdvancedFolder").last_dir（高级文件夹自己的）
   ↓
3. Downloads 文件夹（默认值）
```

修复后，主程序传入空字符串，跳过第1级，直接使用第2级（高级文件夹自己的设置）。
