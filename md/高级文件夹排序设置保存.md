# 高级文件夹功能 - 排序设置持久化

## ✅ 修复的问题

### 问题描述

**现象：**
- 每次打开高级文件夹对话框，排序方式都恢复为默认的"智能排序"
- 每次都要重新选择排序方式（名称/修改日期）
- 升序/降序设置也不保存

**用户反馈：**
> "排序: [智能排序▼] [↑升序] 没有保存，每次都要重新选"

---

## 🔧 解决方案

### 实现方法

使用 `QSettings` 持久化保存用户的排序偏好设置。

**保存的设置：**
1. `sort_by` - 排序方式（natural/name/date）
2. `sort_ascending` - 升序/降序（True/False）

---

## 📋 实现细节

### 修改1：初始化时加载保存的设置

**位置：** `_create_right_panel()` 方法

```python
# 修改前：使用硬编码的默认值
self.sort_by = "natural"  # natural, name, date
self.sort_ascending = True  # True=升序, False=降序

# 修改后：从QSettings加载保存的值
settings = QSettings("MangaTranslator", "AdvancedFolder")
self.sort_by = settings.value("sort_by", "natural")  # 默认值：智能排序
self.sort_ascending = settings.value("sort_ascending", True, type=bool)  # 默认值：升序

# 应用加载的设置到UI控件
index = self.sort_combo.findData(self.sort_by)
if index >= 0:
    self.sort_combo.setCurrentIndex(index)

if self.sort_ascending:
    self.sort_order_btn.setText("↑ 升序")
else:
    self.sort_order_btn.setText("↓ 降序")
```

**关键点：**
- ✅ 使用 `settings.value()` 的第二个参数作为默认值
- ✅ 对布尔值指定 `type=bool` 确保类型正确
- ✅ 立即应用到UI控件，显示上次的选择

---

### 修改2：排序方式改变时保存

**位置：** `on_sort_changed()` 方法

```python
def on_sort_changed(self):
    """排序方式改变"""
    self.sort_by = self.sort_combo.currentData()
    
    # 保存排序设置
    settings = QSettings("MangaTranslator", "AdvancedFolder")
    settings.setValue("sort_by", self.sort_by)
    
    sort_names = {'name': '名称', 'natural': '智能排序', 'date': '修改日期'}
    self._log(f"✓ 排序方式: {sort_names.get(self.sort_by, self.sort_by)}")
    self._reload_all_chapters()
```

**效果：**
- ✅ 用户选择"名称"排序后，下次打开对话框依然是"名称"
- ✅ 立即保存，无需等待对话框关闭

---

### 修改3：升序降序切换时保存

**位置：** `toggle_sort_order()` 方法

```python
def toggle_sort_order(self):
    """切换升序/降序"""
    self.sort_ascending = not self.sort_ascending
    
    # 保存排序设置
    settings = QSettings("MangaTranslator", "AdvancedFolder")
    settings.setValue("sort_ascending", self.sort_ascending)
    
    if self.sort_ascending:
        self.sort_order_btn.setText("↑ 升序")
        self._log("✓ 排序顺序: 升序")
    else:
        self.sort_order_btn.setText("↓ 降序")
        self._log("✓ 排序顺序: 降序")
    
    self._reload_all_chapters()
```

**效果：**
- ✅ 用户切换到降序后，下次打开对话框依然是降序
- ✅ 立即保存，无需等待对话框关闭

## 💾 存储位置

**注册表位置（Windows）：**
```
HKEY_CURRENT_USER\Software\MangaTranslator\AdvancedFolder
├── sort_by = "natural"          (或 "name", "date")
├── sort_ascending = true         (或 false)
├── scan_cache = "{...}"          (扫描结果缓存)
└── last_dir = "D:\漫画\..."      (上次路径)
```

**说明：**
- 所有设置都存储在注册表的同一个位置
- 卸载程序后需要手动清理注册表（可选）
- 设置在不同用户账户之间是独立的

## 📝 技术要点

### QSettings 使用说明

**保存设置：**
```python
settings = QSettings("MangaTranslator", "AdvancedFolder")
settings.setValue("key", value)
```

**读取设置：**
```python
settings = QSettings("MangaTranslator", "AdvancedFolder")
value = settings.value("key", default_value)  # 带默认值
```

**类型转换：**
```python
# 布尔值
bool_value = settings.value("key", True, type=bool)

# 整数
int_value = settings.value("key", 0, type=int)

# 字符串（默认）
str_value = settings.value("key", "default")
```
