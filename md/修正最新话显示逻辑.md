# 修正"最新话/数量"显示逻辑

## 问题描述

**现象**：
- "最新话/数量"列显示的是完整的章节名称
- 例如：`Chapter 57 7a2960 / 3章`
- 章节名太长，显示不美观

**期望**：
- 只显示章节号，例如：`59话 / 3章`
- 简洁明了，一眼看出最新话是第几话

---

## 解决方案

### 修改显示逻辑

从章节名称中**提取数字**，显示为"X话"格式。

#### 1. 多来源情况（作品 → 来源 → 章节）

**位置**：`_load_chapters_for_item()` 方法，创建来源节点时

**修改前**：
```python
source_item.setText(2, f"{info['latest_chapter']['name']} / {info['count']}章")
```

**修改后**：
```python
import re
latest_name = info['latest_chapter']['name']
match = re.search(r'(\d+)', latest_name)
if match:
    chapter_num = match.group(1)
    source_item.setText(2, f"{chapter_num}话 / {info['count']}章")
else:
    source_item.setText(2, f"{latest_name} / {info['count']}章")
```

**效果**：
- `Chapter 59_8ed41d` → `59话 / 3章`
- `Chapter 58_2f5af9` → `58话 / 3章`

---

#### 2. 单来源情况（作品 → 章节）

**位置**：`_load_chapters_for_item()` 方法，单来源分支

**修改前**：
```python
if sorted_chapters:
    latest_chapter = sorted_chapters[-1] if not self.sort_ascending else sorted_chapters[0]
    item.setText(2, f"{latest_chapter['name']} / {len(sorted_chapters)}章")
```

**修改后**：
```python
if sorted_chapters:
    latest_chapter = sorted_chapters[-1] if not self.sort_ascending else sorted_chapters[0]
    import re
    latest_name = latest_chapter['name']
    match = re.search(r'(\d+)', latest_name)
    if match:
        chapter_num = match.group(1)
        item.setText(2, f"{chapter_num}话 / {len(sorted_chapters)}章")
    else:
        item.setText(2, f"{latest_name} / {len(sorted_chapters)}章")
```

**效果**：
- 作品有10个章节，最新是59话 → `59话 / 10章`

---

## 提取逻辑

### 正则表达式
```python
match = re.search(r'(\d+)', latest_name)
```

**说明**：
- `\d+`：匹配一个或多个数字
- 提取章节名中**第一个出现的数字**作为章节号

### 兼容性

**能正确提取**：
- `Chapter 59` → `59`
- `Chapter 59_8ed41d` → `59`
- `第59话` → `59`
- `059 - Title` → `59`（会提取为"059"，显示为"059话"）

**无法提取时**：
- 章节名没有数字（如 `Special Episode`）
- 回退到显示完整章节名：`Special Episode / 1章`

## 显示格式

### 新格式示例

**单来源**：
```
作品名
  59话 / 10章       ← 最新是59话，共10章
```

## 注意事项

### 1. 章节号提取
- 使用正则表达式 `r'(\d+)'` 提取第一个数字
- 适用于大部分常见的章节命名格式
- 特殊格式可能无法正确提取

### 2. 降序排序
- 当排序为降序时，`latest_chapter` 取的是列表第一个元素
- 当排序为升序时，`latest_chapter` 取的是列表最后一个元素
- 保证显示的始终是"最新"的章节

### 3. 向后兼容
- 无法提取数字时，回退到显示完整章节名
- 不会导致显示异常或报错

## 总结

通过从章节名提取数字：

- ✅ 显示更简洁（59话 vs Chapter 57 7a2960）
- ✅ 信息更直观（一眼看出最新话是第几话）
- ✅ 格式统一（都是"X话"格式）
- ✅ 兼容特殊情况（无法提取时显示完整名称）

"最新话/数量"列现在能够清晰地告诉用户：这个作品/来源的最新话是第几话，总共有多少章。
