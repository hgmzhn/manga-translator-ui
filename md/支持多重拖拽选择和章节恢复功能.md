# 支持多重拖拽选择和章节恢复功能

## 问题描述

### 问题1：无法进行多重拖拽选择
**现象**：
- 用户拖拽选择1-3话后，再拖拽选择5-6话
- 第二次选择时，1-3话的选中状态会被清除
- 无法实现间隔选择（跳过第4话）

**原因**：
- 原有的`on_selection_changed`方法会遍历所有章节
- 根据当前选中集合设置复选框状态
- 未选中的项目会被自动取消勾选
- 导致之前的选择被覆盖

### 问题2：双击无法恢复章节选中
**现象**：
- 双击"最近操作"可以定位到作品
- 但无法恢复之前选中的具体章节
- 用户需要重新手动选择章节

**原因**：
- 保存时只记录了作品名和章节总数
- 没有记录具体的章节名称列表
- 双击定位时无法恢复章节选中状态

---

## 解决方案

### 1. 支持Ctrl多重拖拽选择

#### 核心思路
- **增量操作**：只处理选择状态变化的项目
- **状态追踪**：记录上一次的选择状态
- **差异计算**：计算新增和取消的项目

#### 实现细节

**添加状态追踪**：
```python
# 追踪上一次的选择状态，用于支持多重拖拽
self.last_selected_paths = set()
```

**修改选择处理逻辑**：
```python
def on_selection_changed(self):
    """选择改变时同步到复选框（支持Ctrl多重拖拽选择）"""
    # 获取当前选中的章节路径
    current_selected_paths = set()
    for item in selected_items:
        path = item.data(0, Qt.ItemDataRole.UserRole)
        if path and isinstance(path, str) and os.path.isdir(path):
            current_selected_paths.add(path)
    
    # 计算变化
    newly_selected = current_selected_paths - self.last_selected_paths
    newly_deselected = self.last_selected_paths - current_selected_paths
    
    # 只处理变化的项目
    self._toggle_checkboxes_for_paths(root, newly_selected, Qt.CheckState.Checked)
    self._toggle_checkboxes_for_paths(root, newly_deselected, Qt.CheckState.Unchecked)
    
    # 更新状态
    self.last_selected_paths = current_selected_paths.copy()
```

**新增增量切换方法**：
```python
def _toggle_checkboxes_for_paths(self, parent, paths, new_state):
    """为指定路径的项目切换复选框状态（递归）"""
    for i in range(parent.childCount()):
        item = parent.child(i)
        path = item.data(0, Qt.ItemDataRole.UserRole)
        
        if path and isinstance(path, str) and os.path.isdir(path):
            if path in paths:
                item.setCheckState(0, new_state)
        
        # 递归处理子项
        if item.childCount() > 0:
            self._toggle_checkboxes_for_paths(item, paths, new_state)
```

#### 使用方法
1. **拖拽选择**：直接拖拽鼠标选择1-3话
2. **Ctrl追加**：按住Ctrl键，拖拽选择5-6话
3. **结果**：1-3话和5-6话都被选中，第4话未选中

### 2. 记录具体章节信息

#### 增强保存逻辑

**新增章节收集方法**：
```python
def _get_checked_chapter_names(self, item: QTreeWidgetItem) -> List[str]:
    """获取项目下所有被选中的章节名称"""
    chapters = []
    for i in range(item.childCount()):
        child = item.child(i)
        path = child.data(0, Qt.ItemDataRole.UserRole)
        if path and isinstance(path, str) and os.path.isdir(path):
            if child.checkState(0) == Qt.CheckState.Checked:
                chapters.append(child.text(0))  # 保存章节名
        else:
            # 递归处理子项（三层结构时的来源节点）
            chapters.extend(self._get_checked_chapter_names(child))
    return chapters
```

**修改保存结构**：
```python
def _save_recent_works(self):
    # 收集作品和章节详细信息
    selected_data = []  # [{"work": name, "chapters": [ch1, ch2, ...]}, ...]
    for i in range(root.childCount()):
        work_item = root.child(i)
        checked_chapters = self._get_checked_chapter_names(work_item)
        if checked_chapters:

                'work': work_item.text(0),
                'chapters': checked_chapters
            })
    
    # 保存时包含详细信息
    operation = {
        'works': [item['work'] for item in selected_data],  # 兼容旧格式
        'works_detail': selected_data,  # 新增：详细章节信息
        'chapter_count': total_chapters,
```

### 3. 恢复章节选中状态

#### 修改双击定位逻辑

**主要改进**：
```python
def on_recent_work_double_clicked(self, item, column):
    """双击最近操作时跳转并恢复章节选中（支持多个作品）"""
    # 获取详细信息（包含章节列表）
    works_detail = operation.get('works_detail', [])
    if not works_detail:
        # 兼容旧数据：只有作品名，没有章节信息
        works = operation['works']
        works_detail = [{'work': w, 'chapters': []} for w in works]
    
    # 暂时断开信号，避免批量操作触发多次更新
    self.title_tree.itemChanged.disconnect(self.on_item_changed)
    
    try:
        for work_data in works_detail:
            work_name = work_data['work']
            chapter_names = work_data.get('chapters', [])
            
            # 查找作品
            work_item = find_work_item(work_name)
            if work_item:
                # 展开并加载章节
                work_item.setExpanded(True)
                if work_item.childCount() == 0:
                    self._load_chapters_for_item(work_item)
                
                # 恢复章节选中状态
                if chapter_names:
                    checked_count = self._restore_chapter_selection(
                        work_item, chapter_names
                    )
                    self._log(f"  ✓ 找到: {work_name}，恢复选中 {checked_count} 章")
    finally:
        # 重新连接信号并更新统计
        self.title_tree.itemChanged.connect(self.on_item_changed)
        self._update_selection_count()
```

**章节恢复方法**：
```python
def _restore_chapter_selection(self, work_item, chapter_names):
    """恢复作品下的章节选中状态"""
    checked_count = 0
    for i in range(work_item.childCount()):
        child = work_item.child(i)
        path = child.data(0, Qt.ItemDataRole.UserRole)
        
        # 如果是章节项
        if path and isinstance(path, str) and os.path.isdir(path):
            chapter_name = child.text(0)
            # 模糊匹配章节名
            if self._is_chapter_match(chapter_name, chapter_names):
                child.setCheckState(0, Qt.CheckState.Checked)
                checked_count += 1
        else:
            # 递归处理子项（三层结构）
            checked_count += self._restore_chapter_selection(child, chapter_names)
    
    return checked_count
```

**模糊匹配方法**：
```python
def _is_chapter_match(self, chapter_name, chapter_names):
    """检查章节名是否匹配（多种匹配方式）"""
    chapter_clean = chapter_name.replace(' ', '').lower()
    for name in chapter_names:
        name_clean = name.replace(' ', '').lower()
        if (chapter_name == name or 
            name in chapter_name or 
            chapter_name in name or
            chapter_clean == name_clean or
            name_clean in chapter_clean):
            return True
    return False
```

## 功能特性

### ✅ 多重拖拽选择
- **Ctrl+拖拽**：追加选择，不清除之前的选择
- **增量操作**：只修改变化的项目，保留其他选择
- **间隔选择**：支持跳过某些章节进行选择

### ✅ 章节信息记录
- **详细保存**：记录每个作品选中的具体章节名称
- **向后兼容**：保留旧的`works`字段，兼容旧数据
- **扩展性强**：新增`works_detail`字段，可扩展更多信息

### ✅ 双击恢复选中
- **自动定位**：清除搜索过滤，滚动到作品位置
- **恢复选中**：自动勾选之前选中的章节
- **模糊匹配**：支持多种章节名称匹配方式
- **兼容旧数据**：旧格式数据只定位作品，不恢复章节

### ✅ 性能优化
- **信号控制**：批量操作时暂时断开信号连接
- **一次更新**：操作完成后手动触发统计更新
- **递归处理**：支持三层结构（作品→来源→章节）

## 技术细节

### 状态追踪机制
- 使用`self.last_selected_paths`记录上次选择
- 每次选择改变时计算差异
- 只处理变化的项目，不影响其他项目

### 数据兼容性
- 保留`works`字段，确保旧代码可用
- 新增`works_detail`字段，记录详细信息
- 双击时检测数据格式，兼容处理

### 信号管理
- 批量操作前断开`itemChanged`信号
- 避免每次复选框变化都触发更新
- 操作完成后手动触发一次更新

### 匹配策略
- 精确匹配：章节名完全相同
- 包含匹配：章节名互相包含
- 忽略空格：移除空格后匹配
- 大小写不敏感：转小写后匹配
