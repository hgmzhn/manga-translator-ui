# 修复双击定位无法找到作品问题

## 🐛 问题描述

用户双击"最近操作"中的作品时，无法定位到该作品。

从截图看到：
- 最近操作：`已满足上限时, 排挤少女`
- 作品列表中有这些作品
- 但双击后无法定位

---

## 🔍 问题原因分析

### 原因1：搜索过滤导致作品隐藏

**问题**：
- 用户可能使用了搜索功能
- 某些作品被 `setHidden(True)` 隐藏
- 双击跳转时，作品虽然存在但不可见

**影响**：
```python
# 作品被隐藏
work_item.setHidden(True)

# 即使找到并选中，用户也看不到
work_item.setSelected(True)  # 无效，因为被隐藏了
```

### 原因2：名称匹配不够灵活

**问题**：
- 保存的名称：`已满足上限时`
- 列表中的名称：可能是 `已满足上限时 ` (带空格)
- 精确匹配失败

**影响**：
```python
if item_name == work_name:  # ❌ 因为空格不匹配
    # 永远不会执行
```

### 原因3：滚动定位不明显

**问题**：
- 只调用 `scrollToItem()`
- 没有设置为当前项
- 用户可能看不到高亮

---

## ✅ 修复方案

### 修复1：清除搜索过滤

在跳转前清除搜索框，显示所有作品：

```python
def on_recent_work_double_clicked(self, item, column):
    # 清除搜索过滤，确保所有作品可见
    self.search_combo.setCurrentText("")
    self.search_combo.clearEditText()
    
    # 清除当前选中
    self.title_tree.clearSelection()
    
    # 后续查找和定位逻辑...
```

### 修复2：增强名称匹配

使用多种匹配方式：

```python
# 多种匹配方式：精确匹配、包含匹配、忽略空格匹配
item_name_clean = item_name.replace(' ', '').lower()
work_name_clean = work_name.replace(' ', '').lower()

if (item_name == work_name or              # 精确匹配
    work_name in item_name or              # 包含匹配
    item_name in work_name or              # 反向包含
    item_name_clean == work_name_clean or  # 忽略空格精确匹配
    work_name_clean in item_name_clean):   # 忽略空格包含匹配
    # 找到了！
```

### 修复3：改进滚动定位

```python
# 滚动到第一个作品
if first_item:
    self.title_tree.scrollToItem(first_item)
    # 确保第一个作品在视窗顶部
    self.title_tree.setCurrentItem(first_item)  # ✅ 设置为当前项，高亮显示
```

### 修复4：添加调试日志

```python
self._log(f"🔍 正在查找: {', '.join(works)}")

for work_name in works:
    if found:
        self._log(f"  ✓ 找到: {item_name}")
    else:
        not_found.append(work_name)

if not_found:
    self._log(f"⚠️ 未找到: {', '.join(not_found)}")
```

## 📊 匹配规则对比

### 修复前（单一匹配）

```python
if item_name == work_name:
    # 只有完全相同才匹配
```

| 保存的名称 | 列表中的名称 | 匹配结果 |
|-----------|-------------|---------|
| `作品A` | `作品A` | ✅ 匹配 |
| `作品A` | `作品A ` | ❌ 不匹配（有空格） |
| `作品A` | `作品AB` | ❌ 不匹配 |

### 修复后（多重匹配）

```python
if (item_name == work_name or 
    work_name in item_name or 
    item_name in work_name or
    item_name_clean == work_name_clean or
    work_name_clean in item_name_clean):
```

| 保存的名称 | 列表中的名称 | 匹配方式 | 结果 |
|-----------|-------------|---------|------|
| `作品A` | `作品A` | 精确匹配 | ✅ |
| `作品A` | `作品A ` | 忽略空格 | ✅ |
| `作品A` | `作品AB` | 包含匹配 | ✅ |
| `已满足上限时` | `已满足上限时 ` | 忽略空格 | ✅ |

```
┌──────────────────────────┐
│ 多重匹配检查             │

└────┬─────────────────────┘

     │

    滚动到第一个作品
         ↓
    设置为当前项（高亮）
         ↓
    输出日志（成功/失败）
```

## 🔧 技术细节

### 1. 清除搜索过滤

```python
self.search_combo.setCurrentText("")     # 清除选中项
self.search_combo.clearEditText()        # 清除输入文本
```

**效果**：触发 `apply_filter()`，所有作品 `setHidden(False)`

### 2. 忽略空格匹配

```python
item_name_clean = item_name.replace(' ', '').lower()
work_name_clean = work_name.replace(' ', '').lower()

if item_name_clean == work_name_clean:
    # 匹配成功
```

**示例**：
- `"已满足上限时"` → `"已满足上限时"`
- `"已满足上限时 "` → `"已满足上限时"`
- 两者匹配成功 ✅

### 3. 设置当前项

```python
self.title_tree.setCurrentItem(first_item)
```

**效果**：
- 高亮显示该项
- 键盘焦点移到该项
- 更明显的视觉反馈
