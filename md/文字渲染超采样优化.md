# 文字渲染超采样优化

## 问题描述

用户反馈渲染的文字有模糊感，特别是在对话框中的文字边缘不够清晰。

## 原因分析

### 1. 透视变换导致模糊

文字渲染流程：
```
freetype 渲染字符 → 组合成文字层 → 透视变换到目标位置
```

当目标位置比文字层大时，透视变换需要**放大**图像，这会导致：
- 像素被拉伸
- 边缘变得模糊
- 抗锯齿效果下降

### 2. 插值算法的选择

`cv2.warpPerspective` 支持的插值方法：
- `INTER_NEAREST` - 最近邻，速度快但质量差
- `INTER_LINEAR` - 双线性，默认选项
- `INTER_CUBIC` - 双三次，质量较好
- `INTER_LANCZOS4` - Lanczos，质量最好

**注意**：`INTER_AREA` 不适用于 `warpPerspective`，只能用于 `cv2.resize`

## 解决方案

### 超采样渲染

在透视变换前，将文字层放大 2 倍，然后再进行变换。这样可以：
1. 保留更多细节
2. 让透视变换有更多像素可用
3. 最终结果更清晰

### 代码实现

```python
# 位置: manga_translator/rendering/__init__.py

# === 超采样渲染：在更高分辨率下渲染以获得更清晰的文字 ===
# 计算目标区域的大小
dst_rect = cv2.boundingRect(np.round(dst_points[0]).astype(np.int32))
dst_w, dst_h = dst_rect[2], dst_rect[3]
src_w, src_h = box.shape[1], box.shape[0]

# 如果源图比目标大很多（缩小操作），不需要超采样
# 如果源图比目标小或差不多大（放大或保持），使用超采样
scale_factor = max(dst_w / max(src_w, 1), dst_h / max(src_h, 1))

# 超采样倍率：目标越大，需要越高的渲染分辨率
supersample_factor = 1.0
if scale_factor > 0.5:  # 放大或轻微缩小的情况
    # 使用 2x 超采样获得更清晰的边缘
    supersample_factor = 2.0
    box_upscaled = cv2.resize(box, (int(src_w * supersample_factor), int(src_h * supersample_factor)), 
                               interpolation=cv2.INTER_CUBIC)
    box = box_upscaled
```

### 触发条件

| 条件 | 是否超采样 | 原因 |
|------|-----------|------|
| `scale_factor > 0.5` | ✅ 是 | 放大或轻微缩小，需要更多细节 |
| `scale_factor <= 0.5` | ❌ 否 | 明显缩小，源图已有足够细节 |

## 效果对比

### 优化前
- 文字边缘模糊
- 抗锯齿效果差
- 小字体不清晰

### 优化后
- 文字边缘清晰
- 抗锯齿效果好
- 小字体可读性提高
