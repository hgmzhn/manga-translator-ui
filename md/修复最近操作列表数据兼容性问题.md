# 修复最近操作列表数据兼容性问题

## 🐛 问题描述

程序启动时报错：

```
TypeError: string indices must be integers, not 'str'
AttributeError: 'AdvancedFolderDialog' object has no attribute 'log_text'
```

---

## 🔍 问题原因

### 问题1：数据格式不兼容

**旧数据格式**（字符串列表）：
```json
["作品1", "作品2", "作品3"]
```

**新代码期望格式**（字典列表）：
```json
[
  {
    "works": ["作品1", "作品2"],
    "chapter_count": 15,
    "time": "11-24 14:30"
  }
]
```

**冲突**：
```python
operation['works']  # 当operation是字符串时，报错
```

### 问题2：日志未初始化

**调用顺序**：
```
__init__
  ↓
_init_ui()
  ↓
_create_left_panel()
  ↓
_load_recent_works()
  ↓
self._log()  # ❌ 此时 log_text 还未创建
```

**原因**：`log_text` 在 `_create_right_panel()` 中创建，但 `_load_recent_works()` 在 `_create_left_panel()` 中调用。

---

## ✅ 修复方案

### 修复1：数据格式兼容

添加旧格式检测和转换：

```python
def _load_recent_works(self):
    recent_operations = json.loads(recent_data)
    
    # 处理旧格式数据（字符串列表）兼容
    if recent_operations and isinstance(recent_operations[0], str):
        # 转换为新格式
        new_operations = []
        for work_name in recent_operations[:4]:
            new_operations.append({
                'works': [work_name],
                'chapter_count': 0,
                'time': ''
            })
        recent_operations = new_operations
    
    # 后续使用新格式处理
    for operation in recent_operations[:4]:
        works = operation.get('works', [])  # ✅ 安全获取
        # ...
```

### 修复2：错误处理优化

使用 `print` 代替 `self._log`，避免依赖未初始化的控件：

```python
except Exception as e:
    # 错误时不输出日志，避免log_text未初始化错误
    print(f"[AdvancedFolder] 加载最近作品失败: {e}")
```

### 修复3：安全获取字段

使用 `get()` 方法安全获取字段，提供默认值：

```python
works = operation.get('works', [])
time_str = operation.get('time', '')
chapter_count = operation.get('chapter_count', 0)

# 根据字段是否存在，灵活显示
if time_str and chapter_count > 0:
    detail_text = f"{time_str}  ·  {chapter_count}章"
elif chapter_count > 0:
    detail_text = f"{chapter_count}章"
elif time_str:
    detail_text = time_str
else:
    detail_text = "历史记录"
```

## 📊 兼容性处理

### 数据迁移流程

```
加载旧数据
    ↓
检测数据格式
    ↓
┌─────────────────────┐
│ 是字符串列表？      │
└──────┬──────────────┘
       │
       ├─ 是 → 转换为新格式
       │       {
       │         'works': [work_name],
       │         'chapter_count': 0,
       │         'time': ''
       │       }
       │
       └─ 否 → 直接使用
           ↓
       显示数据
```

### 新旧格式对比

| 格式 | 结构 | 信息量 | 兼容性 |
|------|------|--------|--------|
| **旧格式** | `["作品1", "作品2"]` | 只有作品名 | ✅ 自动转换 |
| **新格式** | `[{works, count, time}]` | 作品+时间+章节 | ✅ 完整支持 |

## 🔧 技术细节

### isinstance 类型检测

```python
if isinstance(recent_operations[0], str):
    # 是旧格式（字符串）
else:
    # 是新格式（字典）
```

### 安全字段访问

```python
# ❌ 不安全
works = operation['works']  # 如果没有'works'字段会报错

# ✅ 安全
works = operation.get('works', [])  # 没有字段返回空列表
```

### 错误处理层级

```python
try:
    # 主要逻辑
except Exception as e:
    # 使用print而不是self._log
    # 因为log_text可能未初始化
    print(f"[AdvancedFolder] 错误: {e}")
```

## 💡 向后兼容的重要性

在修改数据结构时，必须考虑：
1. **旧数据的存在**：用户可能有旧格式的数据
2. **平滑迁移**：自动转换，不需要用户手动操作
3. **错误处理**：即使转换失败，也不影响程序运行

这是软件开发中的最佳实践！
