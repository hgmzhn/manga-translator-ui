# 翻译界面

“翻译界面”是桌面端的任务入口，负责维护源文件范围、输出位置、工作流和任务启停。它不用于修改模型参数；模型、API、提示词和规则分别在对应页面管理。

## 页面布局

| 区域 | 控件 | 作用 |
| --- | --- | --- |
| 输入工具栏 | 添加文件、添加文件夹、清空列表 | 建立或重置当前任务范围 |
| 文件树 | 文件夹、归档、图片节点 | 查看层级、处理状态并移除单项 |
| 输出目录 | 路径框、浏览、打开 | 选择并打开最终输出位置 |
| 工作流 | 工作流下拉框 | 从九种互斥流程中选择一种 |
| 任务操作 | 开始/停止 | 启动任务或请求取消当前任务 |

## 添加输入

### 添加文件

“添加文件”支持多选图片，也可选择 PDF、EPUB、CBZ、CBR 和 ZIP 等书籍/归档。归档在处理前会提取图片；具体格式与依赖见 [[文件与目录说明|09-文件与目录说明]]。

### 添加文件夹

“添加文件夹”会递归扫描子目录，按自然顺序组织图片和归档，并忽略工作目录 `manga_translator_work/`。同一目录下的 `2.png` 会排在 `10.png` 前面；文件夹任务输出时会保留相对目录层级。

### 拖放

可把本地文件或目录直接拖入文件树。拖入路径与按钮添加使用同一套文件服务和去重逻辑。

## 使用文件树

文件树按“源目录/归档 → 子目录 → 图片”显示当前任务。节点展开状态和移除记录会在列表重建时保留；大量文件的缩略图按可见范围异步加载，滚动时短暂出现占位图属于正常现象。

- 图片节点会根据关联的 `*_translations.json` 显示“已翻译”或“未翻译”。该状态表示存在可关联 JSON，不保证最终成图已经导出。
- 单击图片节点会选中该图并进入编辑器视图；无需双击。文件夹和归档节点用于展开层级。
- 文件夹和归档节点显示包含的文件数量。
- 点击节点右侧移除按钮只会从当前任务排除该项，不会删除磁盘文件。
- 从已添加文件夹中移除某个子目录或图片后，它会进入本次任务的排除集合；后续刷新列表不会立即把它加回来。
- 移除顶层源路径会同时清理其下的排除记录；“清空列表”会重置全部源路径、排除项和展开状态。

文件树是批量管理的作用域来源。批量页只会扫描当前列表中可关联的 `_translations.json`，因此在主列表移除的文件不会进入批量预览。

## 输出目录

路径框用于显示当前目录。请使用“浏览”选择一个已经存在的目录；当前界面的提示文字虽然提到拖放，但路径框没有接入拖放或手工编辑后的配置写回。“打开”会用系统文件管理器打开当前有效目录。

- 普通文件夹任务在输出目录保留相对子目录。
- 已选择输出目录时，归档提取到 `<输出目录>/<归档名>/original_images/`，成品放在对应的 `<归档名>/`。
- 没有可用输出目录时，归档可先提取到系统临时目录。
- 开启参数“保存到源目录”后，普通输出目录被忽略，结果写入源文件附近的 `manga_translator_work/result/`。
- 关闭“覆盖”时，任务预检查可跳过已有同名结果。

输出路径到源图的关系还会写入 `translation_map.json`，供编辑器反查原稿。不要在任务运行时移动源文件、提取目录或工作目录。

## 选择工作流

下拉框当前依次提供：

1. 普通翻译
2. 导出翻译
3. 导出原文
4. 仅翻译 JSON
5. 导入翻译并渲染
6. 仅上色
7. 仅超分
8. 仅修复
9. 替换翻译

这些模式互斥，不是可叠加开关。切换工作流前先确认对应的 JSON、模板译文或译图是否已经准备好；完整输入、处理阶段和产物见 [[工作流详解|03-工作流详解]]。

## 开始与停止

点击“开始”后，程序先检查任务范围、输出位置、工作流所需 API 和扫描后是否至少有一张有效图片，再加载后端。任务运行期间不能增加、移除或清空文件列表，API 管理也会被禁用。后端启动完成后同一按钮变为停止操作；页面进度区显示状态、当前数/总数、百分比和进度条。

停止用于请求取消当前任务。已经原子写入的 JSON 或已完成图片可能保留，但当前页及尚未处理页面不能视为完整结果；重新运行前应检查日志和输出目录。

## 处理前检查

1. 文件树中只有本次确实要处理的页面。
2. “已翻译/未翻译”状态与所选工作流的前置数据相符。
3. 输出目录可写，“保存到源目录”和“覆盖”状态符合预期。
4. API 管理中当前后端已经测试，参数设置中的组件与之匹配。
5. 先对少量页面试跑，再扩大到完整章节。

第一次使用可按 [[快速开始|01-快速开始]] 操作；遇到导入、归档或输出问题见 [[故障排查|13-故障排查]]。
