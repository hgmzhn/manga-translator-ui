# 可视化编辑器

可视化编辑器用于在成图前或成图后修改译文、文本框、排版、蒙版和图像叠加层。它读写的工程数据是 `manga_translator_work/json/*_translations.json`；对没有 JSON 的图片仍可打开，但不会自动出现可编辑文本区域。

最稳定的入口是先用“普通翻译”、“导出翻译”或“导出原文”生成 JSON，再进入“编辑器视图”。各流程差异见 [[工作流详解|03-工作流详解]]。

## 界面布局

编辑器由顶部工具栏和三栏主区域组成：

- **左侧**：“可编辑译文”与“属性编辑”两个分页。
- **中间**：图像画布、文本框、文字预览、蒙版和叠加层。“对比原图”会切换为左右两面板。
- **右侧**：文件列表，可添加文件/文件夹、移除文件、切换上一张或下一张。
- **顶部**：导出、撤销/重做、缩放、吸附、显示模式、排列和原图不透明度。

三栏之间的分割条可拖动，因此小屏幕上可先收窄暂时不需要的边栏。

## 选区和文本框

选择工具可在画布上选中区域，也可从区域列表选中。编辑器支持：

- 单选、多选和全选文本区域。
- 移动、缩放和旋转文本框，并在画布上即时重新渲染。
- 新增、复制、粘贴和删除区域。
- 使文本框吸附到画布或其他框的对齐位置。
- 开启“从中心缩放文本框”后，拖动尺寸手柄时以中心为锚点。

“排列”菜单允许选择参照物：

- **参照选区**：至少选中两个框后，可左对齐、水平居中、右对齐、顶部对齐、垂直居中和底部对齐。
- **参照画布**：选中一个框就能按画布边界/中心对齐。
- **分布间距**：至少选中三个框后，可水平或垂直等间距分布。

## 译文和属性

“可编辑译文”分页提供区域列表，可批量查找/替换当前页的译文。在列表中修改多条译文后，点击“应用所有翻译更改”提交到画布模型。

“属性编辑”针对当前选区，主要包括：

- 原文、替换前译文（`translation_raw`）、当前译文和字符数。
- 为译文插入占位符或换行。
- OCR 模型、翻译器和目标语言；可只对选中区域重新识别或重新翻译。
- 字体家族、字号、前景色、描边色、描边宽度、行距、字距和角度。
- 对齐方式和横排/竖排方向。
- 样式预设的保存、应用和删除。
- 复制区域、粘贴区域/样式和删除区域。

输入框中的未提交内容会在导出和切图前强制提交，避免刚输入的内容还处于防抖延迟期时丢失。

## 图像编辑层

属性面板的“图像编辑”内含三个分页，它们不是同一张图：

### 蒙版

- 选择、画笔和橡皮擦工具。
- 画笔大小范围为 5 至 200 像素。
- 可切换显示优化蒙版，或清空所有蒙版。
- 蒙版改动会影响修复区域；导出时优先使用优化蒙版，没有时才使用原始蒙版。

### 画笔层

- 选择、彩色画笔和橡皮擦，可设置画笔颜色与大小。
- 可隐藏或显示画笔层，也可单独清空。
- 导出时该 RGBA 叠加层会随工程 JSON 保存，并参与最终合成。

### 印章层

- 选择、仿制印章和橡皮擦，可调整笔刷大小。
- 可单独隐藏/显示和清空印章层。
- 印章结果与彩色画笔层分开保存，撤销/重做也会保留层的区别。

## 富文本编辑

顶部菜单可开启“显示富文本编辑器弹窗”。选中单个区域后，弹窗编辑的是结构化 `richtext.v1` 文档，可对字符范围应用：

- 粗体、斜体、下划线、颜色、描边、外描边、发光和缩放等样式。
- Ruby 注音。
- 竖排文本中的组文字（TCY）。
- 富文本样式预设的保存、改名、应用和删除。

“编辑时自动应用富文本规则”会在提交文本时调用 `config/rich_text_rules.yaml`。自动规则和手动样式的优先级与写法见 [[提示词与规则|06-提示词与规则]]。

## 顶部工具栏

### 菜单

- 导出图片。
- 撤销与重做。
- 放大与缩小；“适应窗口”是单独的常驻按钮。
- 编辑器吸附。
- 从中心缩放文本框。
- 显示富文本编辑器弹窗。
- 编辑时自动应用富文本规则。
- 切换图片时自动导出。

### 显示模式

显示模式只改变编辑器画布，不删除工程数据：

| 模式 | 用途 |
| --- | --- |
| 显示文字和文本框 | 日常编辑，同时检查实际文字与框位置 |
| 仅显示文字 | 检查成品视觉，不显示编辑轮廓 |
| 仅显示文本框 | 检查区域与几何布局 |
| 全部隐藏 | 检查底图、修复和图像叠加层 |
| 与原图对比（双面板） | 同时查看原图和当前编辑结果 |

“原图不透明度”滑块范围为 0% 至 100%。0% 表示不覆盖原图，便于观察修复底图；调高可以检查擦除区域是否过大或偏移。

## 快捷键

下表是 `EditorShortcutManager` 当前真正注册的快捷键：

| 快捷键 | 画布上的行为 |
| --- | --- |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` | 重做 |
| `Ctrl+C` | 复制最后一个选中区域 |
| `Ctrl+V` | 只选中一个区域时，将已复制区域的样式粘贴到它；没有单一选区时，在鼠标位置粘贴一个新区域 |
| `Ctrl+A` | 选中当前图片的所有区域 |
| `Delete` | 删除选中区域 |
| `Ctrl+Q` | 导出当前图片 |
| `Q` | 选择工具 |
| `W` | 蒙版画笔工具 |
| `E` | 蒙版橡皮擦工具 |
| `A` | 上一张图 |
| `D` | 下一张图 |
| `Shift+滚轮` | 调整笔刷大小，限制在 5 至 200 |
| `Ctrl+滚轮` | 按约 5% 步长调整所有选中区域的字号，最小为 1；它不缩放文本框几何尺寸 |

快捷键具备文本输入上下文感知。焦点在译文框或其他文本输入框时，`Ctrl+C/V/A/Z/Y` 会执行标准文本操作，`Q/W/E/A/D` 会正常输入字符，`Delete` 不会误删画布区域。焦点在独立富文本窗口时，主编辑器快捷键不接管该窗口。

> 普通鼠标滚轮由画布用于缩放视图；菜单中也有放大、缩小和适应窗口命令。

## 导出与保存

导出是一个工程同步加成图流程，不会弹出“另存为”对话框：

1. 提交属性面板和富文本编辑器中未落盘的修改。
2. 把区域、蒙版、配置、画笔层和印章层同步到 `manga_translator_work/json/<图片名>_translations.json`。
3. 将当前修复底图写到 `manga_translator_work/inpainted/<图片名>_inpainted.<原扩展名>`。当前没有独立修复图时，会使用底图作为修复图快照。
4. 将渲染任务放入单工作线程的导出队列；成功提示会给出实际输出路径并确认 JSON 已同步。

输出目录按以下顺序确定：

1. JSON 中上次主翻译流程记录的 `last_export_dir`。
2. 若开启“保存到源目录”：源图旁的 `manga_translator_work/result/`。
3. 桌面端记住的最后输出目录（该目录必须仍存在）。
4. 源图所在目录。

文件主名与源图一致。设置中指定输出格式时使用该扩展名；未指定时保留原扩展名。

## 切换图片时的未保存更改

编辑器用撤销栈的 `clean` 状态判断当前图是否有未导出修改。

- 开启“切换图片时自动导出”后，只有发生改动时才排队导出；导出请求无法创建时会取消切图。
- 关闭自动导出后，切图时会询问“导出”、“放弃”或“取消”。选择导出时，会等当前导出成功后再加载目标图。

因为导出会覆写同名 JSON 和成品图，建议在对大量图片做破坏性批量修改前备份 `manga_translator_work/json/`。
